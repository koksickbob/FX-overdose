# P2P 로비 실행 테스트

## 한 PC에서 확인

1. Steam을 실행하고 로그인합니다.
2. Unity에서 `TitleScene`을 열고 Play를 누릅니다.
3. 타이틀 오른쪽의 `P2P MULTI` 버튼을 누릅니다.
4. 전체 로비 화면에 공개 방 목록, 새로고침과 공개·친구 로비 생성 버튼만 보이는지 확인합니다.
5. 상단에 `STEAM READY`, 닉네임과 Steam ID가 보이는지 확인합니다.
6. `친구 로비 생성`을 눌러 특정 로비 화면으로 자동 전환되는지 확인합니다.
7. Lobby ID와 본인 참가자 카드가 표시되는지 확인합니다.
8. 레버리지·마진 버튼을 눌러 규칙 revision이 증가하는지 확인합니다.
9. `친구 초대`를 눌러 Steam Overlay가 열리는지 확인합니다.
10. `나가기`를 누르면 전체 로비 화면으로 돌아오는지 확인합니다.

한 계정만으로는 자기 자신에게 별도 Steam P2P 클라이언트 연결을 만들 수 없습니다. 한 PC 테스트는 로비 생성과 UI 확인까지만 가능합니다.

## 두 계정에서 확인

1. Host 계정이 `친구 로비 생성`을 누르고 Client 계정을 초대합니다.
2. Client가 초대를 수락해 동일 Lobby ID로 들어오는지 확인합니다.
3. Client에서 `준비 / 취소`를 눌러 `[READY]`가 양쪽에 표시되는지 확인합니다.
4. Host가 레버리지나 마진을 바꿨을 때 Client가 `[WAIT]`로 돌아가는지 확인합니다.
5. Client가 다시 준비하고 Host가 `경기 시작`을 누릅니다.
6. Host에는 `[P2P Network] HOST 시작`, Client에는 `[P2P Network] CLIENT 시작` 로그가 나오는지 확인합니다.
7. UI 하단 NGO 상태가 `연결 실행 중`으로 바뀌는지 확인합니다.

## 현재 제한

- 공개 방 검색은 같은 App ID 480, 같은 게임 버전과 같은 지역 검색 범위에서만 결과가 나타납니다.
- Spacewar App ID 480은 여러 개발 게임이 공유하므로 `game=fx_overdose` 필터로 다른 로비를 제외합니다.
- 실제 경기 씬 전환과 시장 동기화는 Phase 5에서 연결합니다.
