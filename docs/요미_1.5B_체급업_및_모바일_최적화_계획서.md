# 요미 AI 체급 1.5B 업그레이드 및 모바일 최적화 계획서

현재 0.5B 모델의 본질적인 문법 붕괴 한계를 극복하기 위해, 모델의 체급을 1.5B로 상향하고 불필요한 지식을 "망각(Catastrophic Forgetting)"시키는 특수 파인튜닝 기법을 적용하여 모바일 최적화를 달성하는 계획입니다.

## User Review Required

> [!IMPORTANT]
> - **모바일 기기 메모리 요구사항:** 1.5B 모델을 Q4_K_M 포맷으로 양자화하면 약 1.1GB ~ 1.3GB의 램(RAM)을 차지합니다. 배포 타겟 안드로이드 기기의 최소 사양이 **RAM 4GB 이상(권장 6GB)**으로 상향됩니다. 동의하시나요?
> - **파인튜닝 학습 시간:** 0.5B 대비 학습 시간이 약 3배(약 40분~1시간) 늘어납니다. 로컬 PC에 그래픽카드가 준비되어 있으신가요?

## Open Questions

1. **데이터셋 재정비:** 현재 모델이 "오빠"를 너무 남발하는 것은 훈련 데이터(yomi_dataset.jsonl)의 모든 문장에 "오빠"가 들어있기 때문입니다. 제가 파이썬 스크립트를 수정해서 기존 데이터셋의 50%에서 "오빠" 호칭을 제거하고, 롱/숏을 명확히 구분하는 새로운 데이터셋을 약 5,000개 분량으로 재생성해 드릴까요?
2. **정수기 필터 유지 여부:** 1.5B로 업그레이드되면 기본 문법이 파괴되지 않으므로, 이전에 유니티 C#에 덕지덕지 붙여두었던 "정규식 교정 사전(Typo Dictionary)" 코드를 깔끔하게 다 지워버리는 게 좋습니다. 동의하시나요?

## Proposed Changes

### 1. 파이썬 파인튜닝 스크립트 수정 (`train_yomi.py`)
- **베이스 모델 변경**: `Qwen/Qwen2.5-0.5B-Instruct` 👉 `Qwen/Qwen2.5-1.5B-Instruct`
- **지식 덜어내기 (Domain-Specific Overfitting)**: 파인튜닝의 학습률(Learning Rate)과 에폭(Epoch)을 기존보다 높게 설정합니다. 이렇게 하면 모델이 원래 알고 있던 수학, 코딩, 외국어 지식을 망각하고 오로지 "한국어 트레이딩 멘헤라" 대사 로직에만 뇌세포를 몰빵하게 되어, 1.5B라는 작은 체급 안에서도 엄청난 고지능을 발휘하게 됩니다. (이것이 불필요한 기능을 덜어내는 원리입니다.)

### 2. 데이터셋 재생성 (`yomi_dataset_generator.py`)
- 기존 2,000개의 데이터를 폐기하고 5,000개로 확장.
- "오빠" 호칭 강제 50% 삭제 (문장 피로도 완화).
- 롱(Long)과 숏(Short) 포지션의 방향성을 모델이 헷갈리지 않도록, 지문과 대사에 방향성 키워드(상승/하락, 돌파/떡락)를 명확히 분리 매핑.

### 3. GGUF 압축 및 유니티 이식
- 학습된 1.5B 모델을 `yomi_1.5b_q4_k_m.gguf` 파일(약 1.2GB)로 양자화 압축.
- 유니티의 `Assets/StreamingAssets/Models/` 폴더에 교체.
- **LLM 엔진 파라미터 롤백**: 0.5B 때문에 억지로 조여두었던 `Temperature`를 다시 0.6으로 높여 창의성을 살리고, `TopK` 제한을 풀어 자연스러운 대사가 나오도록 C# 코드를 롤백합니다.

## Verification Plan

### Automated Tests
- 파이썬 스크립트로 1.5B 모델의 백테스트를 진행하여 "떨려가고", "속아먹어한다" 같은 문법 오류가 단 1건도 발생하지 않는지 검증합니다.

### Manual Verification
- 유니티 에디터에서 플레이하며, C# 교정 사전(Typo Dictionary)이 없어도 롱/숏을 헷갈리지 않고 완벽한 한국어 대사를 구사하는지 확인합니다.
- 모바일(안드로이드) 빌드 후, 램 용량 초과로 게임이 튕기지 않고 쾌적하게 2~3초 내에 대사가 생성되는지 확인합니다.
