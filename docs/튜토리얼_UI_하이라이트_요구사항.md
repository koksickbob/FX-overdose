# 튜토리얼 신규 UI 하이라이트 추가 요구사항 (UI 담당자용)

## 개요
튜토리얼 시나리오가 확장됨에 따라, 플레이어가 새롭게 배워야 할 UI 요소들의 위치를 명확히 짚어주기 위해 **새로운 하이라이트(노란색 테두리 효과)** 작업이 필요합니다.
`TutorialManager.cs` 코드상에 하이라이트를 적용할 수 있는 코루틴 뼈대를 만들어 두었으나, 인스펙터 및 하이라키 상의 연결과 배치가 필요합니다.

## 하이라이트 적용 대상 목록

### 1. 자동/수동 전환 설정 버튼 (또는 옵션)
- **위치:** 메인 화면의 환경 설정(Settings) 내부 혹은 상단바의 특정 토글 버튼
- **설명:** 유저가 직접 자동매매(AI)와 수동매매를 언제든 전환할 수 있음을 알려주는 단계(`Step4_2_AITradingExplanation`)에서 사용됩니다.
- **작업 사항:** 해당 버튼에 튜토리얼 매니저의 `HighlightTarget`을 참조할 수 있도록 연결해주세요.

### 2. AI 성향 (AUTO STYLE) 탭 버튼
- **위치:** 차트 우측 하단의 트레이딩 컨트롤 패널 상단 3개 탭 중 세 번째 (`BtnTabAIStyleMode`)
- **설명:** 요미의 매매 성향(SAFE / BALANCE / AGGRESSIVE)을 조작할 수 있는 탭입니다.
- **작업 사항:** 
  - 기존 레버리지/마진 하이라이트와 동일하게 작동해야 합니다.
  - `TradingPanelUIController`에 탭 자체 혹은 성향 조작 패널 전체를 덮는 하이라이트 `RectTransform`을 노출하여 튜토리얼 매니저가 사용할 수 있게 해주세요.

### 3. 액티브 스킬 (Active Skill) HUD
- **위치:** 튜토리얼 중 액티브 스킬을 사용하는 단축키 슬롯이나 스킬 UI 패널 (`ActiveSkillHUDController` 관할 구역)
- **설명:** 주인공 레벨업 및 스킬 성장을 통해 획득한 특수 능력을 사용하는 단계(`Step8_LevelSystem`)에서 해당 구역을 강조합니다.
- **작업 사항:** 스킬 슬롯들을 감싸는 패널이나 슬롯 하나를 하이라이트할 수 있도록 타겟(`skillHUDHighlight`)을 지정해주세요.

## 참고 사항
튜토리얼 진행 중 스크립트는 `TutorialManager.AutoBindHighlights()` 등의 함수를 통해 동적으로 UI를 찾으려 시도합니다. UI 프리팹이나 씬에서 해당 타겟들의 이름이 변경되지 않도록 주의해 주시고, 튜토리얼 씬 빌드 시 UI 객체들이 정상 활성화 되는지 확인 부탁드립니다.
