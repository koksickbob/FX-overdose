## 1. 범위

월드맵에 **장소**라는 개념을 들이고, 단계별 해금·역행·장소 진입 시 이벤트 선택을 담당한다. 상시 방문 장소인 꽃집의 3기능도 여기 포함된다.

현재 `WorldMapManager`가 아는 것은 **알바**와 **데이트 코스** 둘뿐이고, 장소도 해금도 없다.

## 2. 장소 모델

### 2.1 단계 구성 (§3.1)

| 단계 | 계절 | 장소 |
| --- | --- | --- |
| 1단계 | 여름–가을 | 산책로 · 편의점 · 무인가게 · 코인세탁소 · **집(CP1)** |
| 2단계 | 겨울 | 작은공원 · 만화카페 · 보드게임카페 · 코인노래방 · **전시관(CP2, 핵심 분기)** |
| 3단계 | 봄 | 분식집 · 영화관 · 한강공원 · 한옥마을(즉석사진관) · 미용실 · **수족관(CP3)** |
| 4단계 | 여름 | 옷가게 · 놀이공원 · 워터파크 · 야시장 · 와인바 · 바다 · 반지공방 · 온천여행 · **전망대(CP4, 최종)** |
| 상시 | — | **집 · 꽃집** (단계와 무관하게 항상 열림) |

> 기준 문서 §3.1 표는 1단계를 "가을"로 적었으나 챕터2 본문은 "여름–가을 사이"다. 배경 에셋은 챕터 기준(여름–가을)을 따른다.

### 2.2 장소 데이터

장소 하나가 가지는 것: `Id` · 표시명 · 소속 단계 · 상시 여부 · 방문 여부 · 해당 장소의 이벤트 풀(메인 1건 + 사이드 N건) · B루트 대체 이벤트.

- 장소 정의는 `ScriptableObject`로 둬도 된다 — **대사가 아니라 구조 데이터**라 폰트 프리베이크 제약(D2 4장)에 걸리지 않는다.
- 배경은 장소가 들고 있고, 이벤트가 노드별로 덮어쓴다(`EventNode.BackgroundId`).

### 2.3 진입 처리

```
장소 클릭
  → 시간 슬롯·스태미나·비용 확인 (기존 TryStartDateCourse 자리)
  → 미방문이면 메인 이벤트 재생 (고정)
  → 기방문이면 사이드 풀에서 랜덤 1건 (없으면 "오늘은 별일 없었다" 처리)
  → 방문 기록 · 수치 커밋 · 슬롯 소모
```

- §3의 원칙: **"처음 가는 장소의 이벤트는 고정, 이후 반복 진입은 랜덤으로 1–2개."**
- **장소 순서 일부 고정**: 스크립트 작업량 때문에 한 단계 안에서도 순서를 어느 정도 묶는다(예: 1단계는 편의점 → 산책로). 전체 순서를 강제하지 말고 **선행 장소 1–2개만 지정**하는 정도로 둔다.
- 사이드 이벤트 16건이 아직 미작성이다([추적표](P2_08_01_Event_Tracker.md)). 풀이 비면 진입 자체를 막지 말고 **소모 없이 짧은 안내로 돌려보낸다** — 막으면 CP 진입 조건("모든 장소 1회 방문")과 충돌한다.

### 2.4 기존 데이트 코스와의 관계

`availableDateCourses`(코스명·슬롯·스태미나·비용)는 **장소 진입 비용 테이블로 흡수한다.** 장소가 곧 데이트 대상이므로 코스라는 별도 개념을 유지할 이유가 없다. 알바(`availableJobs`)는 그대로 둔다 — 편의점 타이쿤 씬과 묶여 있고 스토리와 무관하다.

## 3. 단계 해금과 역행

### 3.1 정방향

각 단계의 **CP를 완료하면** 다음 단계가 열린다. 이때 D1의 `AdvanceChapter`가 함께 돌아간다(챕터 증가 · 의존도 −10 · 상한 갱신). **두 곳에서 각각 −10 하지 않도록 D1 쪽 한 곳에서만 처리한다.**

CP 진입 조건은 "일정 시간 경과 또는 이벤트 n회 발생"이며, §3의 "모든 장소를 한 번은 방문해야 주요 이벤트로 진입"이 실질 조건이다. **전수 방문을 기본 조건으로 두고**, 시간 경과는 안전장치로만 쓴다.

### 3.2 역행 (B루트) — 이 문서의 난이도 핵심

CP2 부정 판정 시:

1. 3단계 월드맵이 **해금되지 않는다.**
2. 이미 열린 1–2단계 장소의 이벤트가 **부정 버전(`-B`)으로 교체**된다.
3. 챕터 5-B에서 월드맵이 **2단계 → 1단계로 역행**한다. 요미의 세계가 좁아지는 것을 맵 축소로 표현하는 것이 이 루트의 핵심 연출이다.

구현 방침 — **장소를 지우지 말고 이벤트 풀만 갈아끼운다.** 장소 목록에서 제거하면 방문 기록·배경·UI 배치가 전부 특수 케이스가 된다. `IsBadRoute`가 참이면 같은 장소 ID가 `-B` 이벤트를 돌려주고, 5-B 진입 시 2단계 장소를 **잠금(비활성) 표시**로 바꾼다.

### 3.3 연출 변화 (§3.2)

| 시점 | 변화 |
| --- | --- |
| CP2 부정 | 무채색 전환, 맵 확장 중단 (깨지는 연출 검토) |
| CP2 긍정 | 장소 이벤트가 긍정 버전으로 교체, 정상 확장 |
| CP4 긍정 | 맵 전체 톤 변화 (분홍 테두리·축제 분위기 검토) |

전부 **맵 UI의 컬러 그레이드 한 겹**으로 처리한다. 스프라이트를 따로 뽑지 않는다. 배경 에셋의 같은 규칙은 [A1 배경 스펙](../P2_05_UI_and_Art/P2_05_Story_Background_Asset_Spec.md) 참고.

## 4. 꽃집 (상시 방문)

해금은 챕터2 [꽃집-1]. 챕터4 [꽃집-동행] 전까지는 **주인공 단독 장소**다.

### 4.1 기능 1 — 신세하의 조언

방문할 때마다 현재 루트에 맞는 짧은 조언. 대사 테이블이므로 **`.cs` 정적 테이블**(D2 4장 규약)로 둔다.

### 4.2 기능 2 — 꽃 = 루트 지표

**플레이어에게 현재 좌표를 알려주는 유일한 채널이다.** 의존도를 UI에 노출하지 않기로 결정되면(상위 문서 §7-1), 이 기능이 사실상 유일한 피드백이 되므로 우선순위가 올라간다.

진행 중에는 사분면 궤도를, 엔딩 확정 시에는 엔딩별 꽃을 건넨다. 꽃 목록은 §3.3의 두 표를 그대로 쓴다(진행 중 6종 / 엔딩 18종).

- 판정 입력은 D1의 구간 헬퍼 결과(호감도 구간 × 의존도 구간) 하나뿐이다. 꽃집이 스스로 수치를 해석하지 않는다.
- 꽃말을 몰라도 눈치채도록 **신세하 대사에 의미를 한 겹 섞는다.** (예: 시스투스를 건네며 "이건 하루면 다 져. 그래도 필요하면 가져가.")
- 구입한 꽃을 집 배경 오브젝트로 남겨 상시 표시하는 안은 §3.3에 "고려" 수준으로만 있다. **1차 범위에서 제외**한다.

### 4.3 기능 3 — 요미-신세하 관계 단계

요미가 주인공 이외의 사람과 관계를 만드는 과정. **의존도가 높으면 진행이 막히거나 역행한다.**

| 단계 | 내용 |
| --- | --- |
| 0 | 대면 전. 전해 듣고, 신세하가 보낸 화분을 대신 돌본다 |
| 1 | 요미가 먼저 질문을 건넨다 (챕터4 [꽃집-동행]) |
| 2 | 단둘이 놀러 나가고 주인공에 대한 고민까지 털어놓는다 (의존도 낮은 루트 한정) |

> ⚠️ **기준 문서 내부 불일치.** §3.3은 0–2단계 3구간인데, §4.2 엔딩 격자는 **"신세하 관계 4단계면 친구엔딩 / 3단계 이하면 각자의 길"**을 요구한다. 단계 수를 맞추기 전에는 친구엔딩 판정을 구현할 수 없다. **D4 착수 전에 확정 필요** — 0–4단계 5구간으로 늘리는 쪽이 자연스럽다(3: 요미가 먼저 연락 / 4: 주인공 없이도 유지되는 관계).

**꽃이 집으로 들어오는 순서**(챕터2 꽃 한 송이 → 챕터3 화분 → 챕터4 요미가 직접 고른 화분)는 콘텐츠 쪽 서사 장치이지 시스템이 아니다. 화분 오브젝트는 [A1](../P2_05_UI_and_Art/P2_05_Story_Background_Asset_Spec.md)의 연속성 소품으로 관리한다.

## 5. 완료 판정

1. 1단계 장소 5곳이 열려 있고 2단계 이후는 잠겨 있다.
2. 미방문 장소에 들어가면 메인 이벤트가, 재방문하면 사이드가 나온다. 사이드 풀이 비면 슬롯을 쓰지 않고 돌아온다.
3. 1단계 장소 전수 방문 후 CP1이 열리고, 완료 시 2단계가 해금되며 챕터가 오른다(의존도 −10은 **한 번만**).
4. `IsBadRoute`를 켜면 같은 장소가 `-B` 이벤트를 돌려주고 맵이 무채색이 된다.
5. 꽃집 방문 시 현재 구간에 맞는 꽃이 나오고, 구간이 바뀌면 꽃도 바뀐다.

---

## 6. 하지 않는 것

- 장소별 미니게임. 편의점 타이쿤 외에는 계획에 없다.
- 맵 자유 이동·경로 탐색. 장소는 버튼이다.
- B루트 전용 맵 레이아웃. 3.2의 이벤트 풀 교체로 대신한다.
- 꽃 오브젝트의 집 배경 상시 표시. 4.2 참고.
