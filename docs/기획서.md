게임 이름 : fx overdose

게임 장르 : 시뮬레이션 + 경영 

게임 컨셉 : 비트코인 시장의 트레이더가 되어 성공하기 위해 노력하는 게임

게임 목표 : 게임 내에서 정해진 목표 금액을 달성하면 성공 

사용 엔진 : unity 2d


비트코인 선물 트레이딩 
트레이딩 관련 추가 효과 아이템 구매하여 트레이딩을 하기위한 체력을 증가시키거나, 회복시키고 수익을 얻기, 손해를 더 적게 만들기
ai 트레이더의 기분 관련 추가 효과 아이템을 구매하여 기분에 좌지우지한 투자 방지, 기분을 좋게 할수록 손해 발생시 감소되는 기분을 적게 만들기 등등

이벤트성 플레이어가 직접 선택하는 트레이딩 방향 시스템 (인게임 시간 하루중 한두번 발생하여 이벤트 결과에 따른 추가 수익, 손해 발생)

ai 트레이더 (주인공) 성격 : 멘헤라적인 성향이 강함 (감정적으로 트레이딩을 할 가능성이 있음) - 이를 방지하기 위해 멘탈 컨트롤 아이템을 사용해야함

기본 캐릭터 스탠딩 이미지 4종 (수익률 -100%~-50%, -50%~0%, 0%~50%, 50%~100%이상) 
게임 내에서는 sd 픽셀 캐릭터 사용 (이 또한 수익률에 기반하여 4종의 이미지중 하나가 사용됨)

감정 컨트롤 못하면 손해가 발생(ai 트레이너가 감정적 투자를하여 손해가 발생할 지점에 투자를 진행해버림)

보유 현금이 0이 되면 게임종료예상
ai 트레이너의 기분을 전혀 관리하지 않을 경우 빛내서 투자를 진행하여 배드 앤딩 발생

ai 트레이너의 기본 ai는 qwen 3 0.7b 모델을 int4로 양자화 하여 사용 예정

비트코인 관련 모의 차트 혹은 트레이딩 뷰 제작 필요
