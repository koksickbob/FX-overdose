======================================================
[필독] 하이브리드 AI(LLM) 모델 다운로드 및 설치 방법
======================================================

이 프로젝트는 돌발 이벤트 텍스트 생성을 위해 로컬 AI 모델(Qwen 1.5B)을 사용합니다.
모델 파일은 용량이 1GB가 넘어 깃허브에 올라가지 않으므로, 프로젝트를 처음 받으신 분들은 반드시 아래 링크에서 모델을 직접 다운받아 넣어주셔야 합니다.

📌 다운로드 링크 (HuggingFace 공식 드라이브):
https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf

📂 설치 위치:
다운받은 `qwen2.5-1.5b-instruct-q4_k_m.gguf` 파일을 아래 경로에 그대로 넣어주세요.
-> Assets/StreamingAssets/Models/
