# P2 LLM Architecture & Prompt System Specs

## 1. 개요
본 문서는 `FX OVERDOSE` 프로젝트에서 온디바이스 로컬 LLM을 연동하여 게임 내 이벤트 시나리오와 대사를 동적으로 생성하는 시스템의 최종 명세서입니다. 
기존 기획 문서(`Phase1_Backup/생성형AI_활용_프롬프트_정리.md`)에서 논의되었던 구버전 모델 연결 방식에서 진일보하여, **LLMUnity** 패키지를 기반으로 한 비동기 추론 인터페이스와 엄격한 JSON 파싱, 한국어 유효성 검증을 포함한 실제 코드(`LLMSafeGenerator.cs`) 기준 아키텍처를 정의합니다.

## 2. LLM 연동 아키텍처
- **사용 패키지**: `LLMUnity` 플러그인 (`LLM`, `LLMAgent` 컴포넌트 사용)
- **핵심 관리 클래스**: `FXOverdose.AI.LLM.LLMSafeGenerator` (싱글톤 패턴으로 씬 전환 시에도 유지)
- **통신 방식**: 유니티 메인 스레드를 멈추지 않도록 비동기(`async/await`) 방식으로 `Task`를 반환하며, `llmAgent.Chat()` 메서드를 통해 백그라운드에서 추론을 진행합니다.

## 3. 핵심 페르소나 및 프롬프트 명세

### A. 돌발 선택 이벤트 생성 프롬프트 (`GenerateChoiceEventAsync`)
돌발 이벤트(Choice Event) 발생 시, 현재 시장 상황(Market Context)과 이벤트 테마(Theme Tag)를 바탕으로 시나리오 제목, 설명, 그리고 파트너 AI '요미'의 반응 대사를 실시간으로 창작합니다.

**적용된 '요미' 페르소나 (실제 인게임 프롬프트 주입 내용)**:
> "플레이어의 파트너 AI '요미'의 반응(AIMonologue)도 작성해야 합니다. 요미는 플레이어를 '마스터'라고 부르며, 감정적이고 호들갑을 잘 떠는 귀여운 성격입니다."

**[프롬프트 내 퓨샷(Few-Shot) 예시]**
- "마스터...! 거래량 왜 이래?! 찌라시가 돌고 있어! 진짜라면 지금 안 타면 우리 시드 다 날아간다고!! 아씨... 롱 쳐야 해?!"
- "안 돼... 출금 중단이라니... 내 시드가 묶이면 끝이야... 싹 다 던져버려야 해... 지금 당장 숏으로 쳐박아야 된다고!!"
- "파웰 총재 입에서 긴축 발언이 나왔어...! 이건 그냥 차트 구조가 무너지는 거잖아... 당장 손절해야 돼... 아니 물타야 하나?!"

**입력 및 출력 제약사항**:
반드시 아래 JSON 양식으로 출력되어야 하며, 영어나 한자, 중국어를 엄격히 금지하고 오직 한국어(Korean)로만 응답하도록 시스템 차원에서 강제하고 있습니다.

```json
{
  "ScenarioTitle": "[한국어로 이벤트 제목 작성]",
  "ScenarioDescription": "[한국어로 이벤트 상황 묘사 작성]",
  "AIMonologue": "[이 상황에 대한 요미의 다급한 한마디]"
}
```

### B. 일일 정산 일기 생성 프롬프트 (`GenerateDailySettlementAsync`)
당일 발생한 수익률(`todayProfit`)과 강제 청산 횟수(`liquidations`)를 요약하여, 1문장 분량의 짧고 직관적인 한국어 트레이딩 일기를 작성합니다.

## 4. 안전 및 예외 처리 (Safe Fallback System)
LLM의 확률적 특성상 포맷을 어기거나 엉뚱한 언어(할루시네이션)를 반환할 가능성에 대비해, 아래와 같은 강력한 3단계 안전망이 구현되어 있습니다.

1. **JSON 정제 및 정규화 (Regex Clean-up)**:
   - LLM 응답 텍스트에서 `{` 와 `}` 사이의 내용만 우선적으로 추출합니다.
   - `JsonUtility`의 대소문자 엄격성에 대응하기 위해, `Regex.Replace`를 활용하여 소문자로 잘못 생성된 키값(예: `"scenarioTitle"`)을 올바른 파스칼 케이스(`"ScenarioTitle"`)로 정규화합니다.

2. **한국어 판독기 (`IsValidKoreanText`)**:
   - 생성된 결과물 텍스트를 순회하며 한글 유니코드 음절(`0xAC00 ~ 0xD7A3`)이 최소 5글자 이상 포함되었는지 철저하게 검사합니다. 
   - 폰트 에셋에 한글만 구워져 있는 경우 중국어나 영어가 섞이면 네모(□)로 깨지는 문제를 방지하기 위해, 한국어가 아니라고 판독되면 결과물을 즉시 폐기합니다.

3. **더미 데이터 풀백 (Dummy Data Fallback)**:
   - LLM 에이전트 미연결, JSON 파싱 실패, 필수 필드 누락, 또는 한국어 판독 실패 시 게임 진행이 멈추거나 빈칸이 뜨는 것을 막기 위해 미리 정의된 기획 더미(Dummy) 데이터를 즉시 반환하여 게임 흐름을 정상적으로 이어갑니다.
