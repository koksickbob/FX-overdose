# UI 프리팹 Git 동기화 누락 해결 가이드

유니티 협업 과정에서 **"내 자리(로컬)에서는 잘 되는데 다른 사람 자리에서는 작동하지 않거나 에러가 나는 현상"**의 99%를 차지하는 프리팹 동기화 누락 문제를 해결하는 가이드입니다. 해당 가이드를 UI 담당자분께 전달하여 이슈를 빠르게 해결해 보세요.

---

## 🛑 현재 발생한 문제 상황

*   **UI 담당자 (dev_ui) 환경:** 하이라이트 기능이 완벽하게 정상 작동함.
*   **타 개발자 (Pull 받은) 환경:** 하이라이트가 엉뚱한 곳에 그려지거나 전혀 보이지 않음.

> [!WARNING]
> **원인 요약**
> UI 담당자분께서 유니티 에디터 상에서 작업하신 UI 계층 구조 변경(빈 오브젝트 추가, 부모-자식 관계 변경 등) 내역이 담긴 **프리팹 파일(`.prefab`)이 Git 커밋에서 누락**되었습니다. 코드(`.cs`)만 최신이고 프리팹은 과거 버전이라 서로 아귀가 맞지 않아 고장이 발생한 상태입니다.

---

## 🛠️ 해결 방법 (UI 담당자 작업)

UI 담당자분께서는 본인의 컴퓨터에서 아래 절차를 진행해 주셔야 합니다.

### 1. Git 클라이언트(소스트리, 깃허브 데스크탑 등) 열기
현재 작업 중인 브랜치(`dev_ui`)의 '커밋하지 않은 변경 사항(Unstaged Changes)' 목록을 확인합니다.

### 2. 누락된 프리팹(.prefab) 파일 찾기
스크립트(`.cs`)는 이미 푸시하셨지만, 아래와 같은 확장자를 가진 파일들이 아직 커밋 대기열(Staging Area)에 올라가지 않고 남아있는지 확인합니다.
*   `*.prefab` (예: TopStatusBarUI.prefab)
*   `*.unity` (씬을 직접 수정하신 경우)
*   `*.asset`

### 3. 파일 추가(Stage) 후 커밋(Commit) & 푸시(Push)
> [!IMPORTANT]
> 누락된 프리팹 파일들을 모두 체크(Stage)한 뒤, **"UI 하이라이트 타겟 프리팹 적용"** 등의 메시지와 함께 새로 커밋하고 브랜치에 푸시해 주세요.

---

## ✅ 확인 절차 (타 개발자 작업)

UI 담당자님께서 누락된 프리팹 파일을 푸시하셨다고 연락을 주시면, 문제가 발생했던 개발자분은 다음을 수행합니다.

1. 터미널이나 Git 클라이언트에서 **`git pull`**을 실행합니다.
2. 유니티 에디터로 돌아가 프리팹(예: `TopStatusBarUI.prefab`) 내부 계층 구조에 `TutorialBalanceHighlightTarget` 등의 더미 오브젝트가 정상적으로 추가되었는지 확인합니다.
3. 플레이 모드를 실행하여 하이라이트 기능이 정상 작동하는지 테스트합니다.
