## 반영한 리뷰 결정

- 원래 명세의 어두운 폐인 방 대신, 이후 승인된 밝고 깨끗한 방과 셀 일러스트를 계승했다. 캔·잡지·휴지 등 쓰레기는 추가하지 않았다.
- 아침 v05와 그 조명 제거 바탕을 공통 구조로 사용했다. 신규 배경 생성본에서 부드러운 RGB 조명 배율을 추출해 공통 바탕에 적용하므로 벽·바닥·창·커튼의 선을 시간대마다 다시 그리지 않는다. 밤의 작은 도시 점등만 추가했다.
- 점심 직사광은 기존 `Solar_Projection_v01.json`의 남동향 창·북위 37°·춘추분·태양시 12시 계산을 사용한다. 아침처럼 앞쪽에 긴 빛을 두지 않는다.
- 같은 남동향 가정에서 저녁의 긴 직사광은 성립하지 않아, 노을 하늘의 난색 간접광으로 표현했다. 임의의 창틀 그림자는 추가하지 않았다.
- 문은 채택 배경의 실제 오른쪽 벽에 맞게 정렬했다. 침대는 높이 검토 v02의 낮은 머리판·앞쪽 배치 방향을 반영했다.
- 문이 침대에 가려지는 실제 알파 면적은 **9.65%**로 30% 이내다. 문 손잡이는 가려지지 않는다. 가려지는 문 픽셀은 최종 문 레이어에서 제거했다.
- 오브젝트 4장 모두 요미 예약 영역 `x700~1220, y160~1080`의 알파 픽셀이 **0개**다. 탁자 위 꽃 확장 공간도 비웠다.

## 규격과 검수

- 모든 납품 PNG: **1920×1080 / RGBA 8bit / sRGB ICC 프로필 / 캔버스 트리밍 없음**.
- 배경 알파는 전부 255. 오브젝트는 실제 알파 0~255이며 체크무늬가 그려진 파일이 아니다.
- 물체 실루엣과 인접한 2px 안티에일리어싱만 유지하고 멀리 떨어진 미세 알파를 제거했다. 바닥 그림자는 배경에만 포함한다.
- Unity `.meta`: Sprite Single, Bilinear, Full Rect, Max Size 2048, Mipmap Off. 오브젝트는 Read/Write On·Compression None, 배경은 Read/Write Off·High Quality.
- [수치 검수와 SHA-256](검수_결과.json)에 실제 클릭 면적·영역·가림 비율·PSD 재열기 결과를 기록했다.
- 현재 포인트 앤 클릭 런타임 빌더는 이 Resources 경로를 자동으로 읽는다. 기존 탑다운 에셋, 게임 코드, 씬, 빌드 설정은 변경하지 않았다.

## 원본과 재현

- 원화 생성: **내장 image_gen**, CLI/API 폴백 사용 없음.
- [전체 생성 프롬프트](생성_프롬프트.json), [컴퓨터 원근 수정 프롬프트](컴퓨터_원근_수정_프롬프트.txt), `sources/`의 원본 출력 보관.
- 기존 리뷰에서 승인된 계산 마스크 후처리의 연속 작업으로 알파 정리·좌표 정렬·조명 보정·PNG/PSD 패키징을 수행했다.
- `assemble_assets.py`: 생성본에서 정렬된 PNG 및 합성 JPG 조립. `package_assets.py`: Unity 설치·PSD/ZIP 출력.
- 실행 의존성: Python + Pillow, NumPy, SciPy, psd-tools. 이번에는 프로젝트 외부 임시 가상환경 `/private/tmp/yomi-assets-venv`를 사용했다.

## 남은 실제 게임 확인과 한계

- PSD는 **1080p 정렬본을 2배 보간한 편집용 4K 묶음**이다. 생성 당시부터 네이티브 4K로 그린 원화나 조명의 원본 브러시 레이어는 아니다.
- 요미 원본은 변경하지 않았다. 합성 JPG에서만 원본의 투명 여백을 제외한 실루엣을 높이 760px, 발바닥 y940에 맞췄다. 런타임 빌더가 전체 스프라이트 사각형을 기준으로 배치하므로 실제 게임의 발 위치에는 미세한 차이가 있을 수 있다.
- 방과 가구는 리뷰에서 추정한 공간에 맞춘 일러스트이며 실측 3D 모델이 아니다. 모든 가구 선의 단일 소실점 수렴을 수학적으로 통과했다고 주장하지 않는다.
- Unity Play, 실제 알파 클릭, 16:10·21:9 화면비 테스트는 실행하지 않았다. `FX Overdose/Build YomiRoom PointClick Test Scene`으로 테스트 씬을 만들고 확인할 수 있다.
- 선택 발주인 호버 4장과 시간대별 가구 변형 12장은 포함하지 않았다. 네 시간대에 공용 중간톤 가구를 사용한다.
