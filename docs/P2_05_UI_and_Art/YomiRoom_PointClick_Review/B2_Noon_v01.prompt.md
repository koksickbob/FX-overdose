## 제작 및 검수 기록

- 아침 v02의 밝고 깨끗한 방과 정면 구도를 이어갔다. 쓰레기와 가구를 추가하지 않았다.
- 창밖과 실내 중간톤을 밝히고 바닥 채광을 주황보다 옅은 금빛·크림빛으로 변경했다.
- 창가 램프의 발광을 껐다. 램프와 화분은 원래 자리에서 유지했다.
- 육안으로 창·커튼·벽 모서리·바닥 널판 등 주요 배치를 비교했다. **시간대 간 픽셀 단위 정렬은 아직 통과 판정하지 않았다.**
- 생성 파일을 바이트 변경 없이 검토 폴더에 복사하고 SHA-256 일치를 확인했다.
- 원본 파일 경로를 읽는 도구가 샌드박스 초기화 오류로 실패했다. 원본을 변경하지 않고 메모리에서 JPEG 미리보기로 읽어 확인한 뒤, 대화에 표시된 미리보기를 참조한 내장 이미지 편집으로 1장을 생성했다.
- 최종 납품 전 공통 1920×1080 내보내기, 원본과의 정밀 정렬, 후속 가구 레이어 합성이 필요하다. 승인 없이 추가 수정 시안이나 다음 에셋을 생성하지 않는다.

점심 조명 변경:
- 원본의 따뜻한 오전보다 더 밝고 선명한 한낮 자연광. 창밖은 거의 흰빛의 옅은 푸른 하늘과 밝은 구름이며 같은 스카이라인의 안개만 줄여 건물을 조금 더 선명하게 한다. 건물을 추가하거나 위치를 바꾸지 않는다.
- 원본의 주황빛 아침 바닥 햇살을 더 중립적인 연한 금빛/크림빛 정오 햇살로 바꾼다. 창 근처 바닥의 채광은 넓고 밝고 부드럽다. 방 전체를 노란색으로 칠하지 않는다. 바닥 중앙의 캐릭터 자리는 중립색 확산광이 남는다.
- 태양이 더 높은 시간대로 읽히도록 창의 투사광과 블라인드 그림자는 원본보다 짧고 창 쪽에 모인다. 빛이 닿는 주변은 부드러운 확산광으로 더 밝게 읽힌다. 왼쪽 벽의 긴 아침 빛 줄무늬는 길이와 강도를 낮추고 위쪽에서 오는 자연광으로 부드럽게 만든다. 물체 윤곽선은 바꾸지 않는다.
- 창턱 오른쪽 작은 앰버 램프는 반드시 꺼진 상태. 불꽃/노란 광원/노란 번짐을 제거하고 같은 램프의 유리와 금속을 자연광 아래에서 보이게 한다. 램프 자체는 삭제하거나 새 모양으로 그리지 않는다.
- 푸른 회색 벽은 원래 색을 유지하면서 오전보다 살짝 밝은 중간톤. 창 주변이 가장 밝고 모서리에는 부드러운 그림자가 남는다. 하얀 벽으로 바꾸지 않는다. 하이라이트가 날아가거나 바닥 널판이 뭉개지지 않는다.
