# B1 아침 배경 v02 — 청소·아침 조명·화풍 재해석

- 도구: 내장 `image_gen`
- 편집 대상: [B1_Morning_v01.png](B1_Morning_v01.png)
- 화풍 기준: `Assets/Resources/DatingSim/Emotions/Sprites/T1/Calm.png`
- 출력: [B1_Morning_v02.png](B1_Morning_v02.png)
- 실제 출력 규격: 1672×941, PNG, RGB 8bit, 불투명. 요청한 1920×1080과 달라 컨펌용 시안으로 보관한다.
- 상태: 사용자 채택 완료. 후속 오브젝트 레이어의 화풍·밝기·배치 기준으로 사용한다.

## 사용자 수정 요청

1. 방 안의 쓰레기 표현을 전부 없애고 깔끔하게 수정한다.
2. 아침 배경으로 읽히도록 실내를 밝힌다.
3. 요미 `T1/Calm` 에셋을 분석해 그 화풍으로 재해석한다.

이 지시가 원래 명세의 쓰레기 소품 유지, 강한 비네팅, 화면 대부분을 어둡게 유지하는 조건보다 우선한다.

## T1/Calm 육안 분석과 배경 적용

| 관찰한 표현 | 배경에 적용한 방향 |
| --- | --- |
| 짙은 차콜의 가는 윤곽선과 가벼운 내부 선 | 창틀·몰딩·바닥의 외곽을 정갈한 선으로 정리 |
| 머리카락의 큰 면과 절제된 회청색 하이라이트 | 커튼·벽을 큰 명암 면으로 표현하고 미세 질감을 줄임 |
| 흰 티셔츠의 회보라색·회청색 셀 명암과 부드러운 경계 | 푸른 회색 벽에 넓고 부드러운 그림자 적용 |
| 피부의 밝은 크림색과 낮은 대비의 온화한 음영 | 밝은 확산광과 부드러운 황금빛 바닥 햇살 |
| 디테일과 채도를 제한한 하이라이트 | 강한 주황빛과 사진 같은 재질 표현을 완화 |

## 실제 전달한 프롬프트

```text
용도: style-transfer. FX OVERDOSE 게임의 요미의 방 B1 아침 배경 v02 수정본, 컨펌용 이미지 정확히 1장.

입력 1 B1_Morning_v01.png = 편집 대상. 이 방의 정면 구도와 공간, 창문/커튼/블라인드/몰딩/화분/램프의 위치를 보존하면서 바닥 쓰레기를 전부 없애고, 조명과 전체 그림체를 다시 그린다.
입력 2 T1/Calm.png = 가장 중요한 화풍 기준. 캐릭터 원본의 그림체만 건축과 소품으로 옮긴다. 이 캐릭터는 이미지에 합성하거나 새로 그리지 않는다. 입력 2의 투명 배경이 검게 보이는 것은 조명·팔레트 참고가 아니다.

사용자의 최신 수정 지시가 이전의 어둡고 쓰레기 많은 방 설정보다 우선한다:
1. 방 안에 표현된 쓰레기 전부 제거.
2. 실내가 너무 어두우므로 아침이라는 것이 명확하게 느껴질 만큼 밝게 변경.
3. 기존 시안의 화풍도 T1/Calm 에셋을 면밀히 분석한 결과에 맞춰 재해석.

청소:
왼쪽 아래 바닥의 캔들, 잡지 더미, 구겨진 휴지; 왼쪽 안쪽 벽 근처 캔; 오른쪽 안쪽 바닥의 잡지와 캔; 오른쪽 아래 캔과 휴지까지 전부 제거한다. 남아 있는 캔, 잡지, 책, 휴지, 종이, 쓰레기, 작은 파편이 한 개도 없게 한다. 쓰레기의 그림자, 잔상, 얼룩도 제거한다. 빠진 자리는 원목 바닥의 정상적인 널판과 이음새로 자연스럽게 이어 그린다.
전체 바닥은 깨끗하고 넓게 비어 있는 정돈된 방이다. 벽에 보이는 갈색 얼룩·긁힘·먼지·거친 때도 정리한다. 창턱의 식물 화분과 작은 앰버 램프는 유지한다. 소품을 새로 추가하지 않는다.

화풍 분석과 적용 — 단순 노출 보정이 아니라 이미지 전체의 선화·명암·질감 재해석:
T1/Calm의 윤곽은 짙은 차콜의 가늘고 매끈한 선으로 정리되며, 내부 선은 더 가볍다. 배경도 정갈하고 가는 선화를 사용한다.
머리카락의 명암은 작은 결을 수없이 그리기보다 크고 명료한 면과 절제된 회청색 하이라이트로 읽힌다. 커튼 주름과 몰딩도 큰 면과 깔끔한 그림자로 표현한다.
흰 티셔츠는 밝은 바탕 위에 회보라색·회청색의 넓은 셀 명암과 약간의 부드러운 전이가 섞여 있다. 이를 벽·창틀·바닥의 명암 처리에 적용한다.
피부는 밝은 크림 톤의 넓은 평면과 낮은 대비의 따뜻한 음영이다. 방의 아침빛도 밝고 부드러운 크림빛으로 표현한다.
이 특징들이 동일한 일러스트레이터가 요미를 위해 그린 비주얼노벨 배경처럼 통일되어야 한다. 단순히 사실적인 방에 애니메이션 필터를 씌운 모습은 피한다.
고해상도 손그림 애니메이션/게임 일러스트. 얇고 깔끔한 선, 큰 셀 명암 면, 부드럽고 정돈된 디지털 브러시 전이, 절제된 재질감. 바닥 나뭇결은 듬성듬성 간결한 선과 색면으로 정리한다. 거친 붓 질감, 미세 노이즈, 점묘, 사진 같은 나뭇결, 오염된 텍스처, 과한 3D 광택, 검정 덩어리, 픽셀아트 금지. 과장된 만화 두꺼운 외곽선이나 유아용 장난감 스타일도 금지.

아침 조명:
기존의 밤처럼 캄캄한 실내와 강한 검정 비네팅을 없앤다. 창의 아침 자연광이 벽·천장·바닥에 충분히 확산되고 반사되어 좌우 벽까지 색과 형태가 읽히게 한다. 전체 중간톤을 확실하게 올린다. 밝고 조용한 오전의 실내이며, 창 밖만 밝고 실내는 암흑인 노출 실패가 아니다.
벽의 고유색은 저채도 푸른 회색/슬레이트 네이비를 유지하되, 그림자에서도 청회색 면이 또렷하게 보이고 거의 검정으로 뭉개지지 않는다. 벽을 하얀 방으로 바꾸지는 않는다.
천장과 뒷벽은 부드러운 중간 명도의 회청색. 창가가 가장 밝고 양옆으로 완만하게 어두워진다. 구석도 부드러운 음영 정도로만 처리한다.
나무 바닥은 따뜻하고 편안한 밝은 중간톤의 월넛/꿀빛 갈색. 기존의 강한 주황색 불길 같은 빛 웅덩이를 부드러운 연한 황금빛 햇살로 바꾼다. 블라인드 줄무늬 빛은 바닥에서 읽히되 깨끗하고 부드럽게 표현한다.
창밖은 밝은 크림빛 아침 하늘과 옅은 푸른 도시 스카이라인. 붉은 노을이나 주황색 일몰 느낌 금지.
앰버 램프는 켜져 있으나 자연광보다 훨씬 약한 작은 따뜻한 포인트다.
요미가 서는 화면 중앙의 빛은 거의 중립적인 밝은 확산광으로, T1/Calm의 밝은 피부와 흰 티셔츠가 자연스럽게 어울리게 한다.

공간 보존:
입력 1과 동일한 중앙 정면 1점 투시, 동일한 시선과 렌즈, 중앙 창문, 좌우 벽, 천장, 넓은 빈 바닥. 새 방으로 바꾸거나 카메라를 회전하지 않는다. 창과 커튼의 모양, 화분과 램프의 위치도 유지한다. 방의 선과 가구 자리 배치는 유지하되 질감과 명암 표현을 위 지시대로 새로 그린다.
중앙 x700~1220(1920px 기준)은 이후 캐릭터를 올릴 자리로 비워 둔다. 왼쪽 컴퓨터 자리와 오른쪽 침대·협탁·문 자리는 이후 독립 오브젝트를 올릴 빈 벽·바닥으로 유지한다.
새 가구, 침대, 책상, 의자, 모니터, 폰, 문, 문 구멍, 러그, 액자, 글자, UI, 인물, 사람 그림자를 그리지 않는다.

출력:
수정한 방 배경 단일 이미지 1장, 16:9 가로, 1920×1080 PNG 전체 불투명, sRGB. 가능하면 원본의 1672×941 크기를 답습하지 않고 요청한 최종 캔버스에 재렌더한다. 비교 이미지·분할 화면·스타일 분석 시트·글자·가이드·워터마크·테두리는 없다.
최종 확인: 쓰레기 0개, 밝은 아침 실내, T1/Calm과 동일 계열의 선과 셀 명암, 입력 1의 방 구도 유지.
```
