침대 높이를 포함한 문 가림 검토 · v02

채택 배경에 입체 블록을 투영한 오른쪽 벽 확대도입니다. 침대는 매트리스·머리판·베개의 높이까지 포함합니다.

v01의 “66px 간격이면 문과 침대가 분리된다”는 결론을 철회합니다. 바닥 자리만으로 실제 가림을 판단할 수 없습니다.

기존 뒤쪽 자리 + 높이 반영

머리판 1.00m / 매트리스 상단 0.48m / 베개 상단 0.63m

앞으로 당긴 안 · 일부 가림 유지

보라색·남색: 침대 입체 블록 / 붉은 사선: 침대의 보수적 외곽이 문과 겹치는 영역 / 노란 세로 화살표: 바닥부터 머리판까지 높이
수치는 검토용 투시 모델의 결과이며 실제 에셋의 가림 비율이 아닙니다. 바닥의 출입 공간이 남아 있어도 화면에서는 앞 가구가 문을 가릴 수 있습니다.

검토 기준과 조절 방법

머리맡 거리는 카메라에서 침대 머리맡까지의 거리입니다. 줄이면 침대를 앞으로 당깁니다. 침대 길이는 2m로 유지하므로 발치가 더 많이 화면 밖으로 나갑니다.

항목가정
침대폭 1m × 길이 2m, 프레임 상단 0.28m, 매트리스 상단 0.48m, 베개 상단 0.63m
문폭 0.9m × 높이 2m, 오른쪽 벽. 손잡이 높이 1m
카메라눈높이 1.35m, 소실점 (960,300). 채택 배경의 벽·바닥 경계와 요미의 크기에 대략 맞춘 검토용 보정
가림 계산침대 구성 요소의 모든 꼭짓점을 투영하고 이를 감싸는 외곽을 문과 비교. 실제 틈새보다 보수적으로 계산

“낮은 침대·완전 분리 검토”는 머리판 0.50m, 머리맡 거리 2.08m로 둡니다. 이 모델에서는 겹침이 없어지지만 침대가 낮아지고 발치 대부분이 잘립니다. 아직 채택한 가구 디자인은 아닙니다.
