# B1 아침 배경 v05 — 질감 정리 및 1920×1080 확대

- 결과: [B1_Morning_v05.png](B1_Morning_v05.png)
- 상태: **사용자 컨펌 대기**. 다른 시간대나 오브젝트는 이번에 만들지 않았다.
- 실제 규격: **1920×1080, 불투명 PNG, RGB 8bit, sRGB 태그**.
- 사용자 요청: “후보정 혹은 업스케일링이 좀 필요해 보여. 지금 너무 잡티가 많은 느낌이야.”
- 방식: 승인된 코드 후처리. 추가 이미지 생성은 사용하지 않았다.
- 기준: [아침 v04](B1_Morning_v04.png)의 구도·조명과 그 제작에 사용한 조명 제거 작업 바탕.
- 재현: [cleanup_morning_v05.py](cleanup_morning_v05.py)
- 기반 생성 프롬프트: [B1 v03 기록](B1_Morning_v03.prompt.md)

## 처리 내용

1. 조명 제거 작업 바탕에 중간값 필터를 약하게 혼합하여 고립된 점과 작은 보정 흔적을 줄였다.
2. 색 차이가 큰 경계를 넘지 않는 5×5 양방향 필터로 바닥·벽의 미세한 질감을 완화했다. 창틀·커튼·식물과 바닥 이음새는 육안으로 확인했다.
3. Lanczos 보간으로 전체 캔버스를 1920×1080에 대응시켰다. 크롭이나 카메라 변경은 없다.
4. 기존 광선 투영 좌표를 가로 1920/1672, 세로 1080/941 비율로 매핑하여 직사광과 중앙 창틀 마스크를 새로 래스터화했다. 원본의 극미한 화면 비율 차이도 이 대응에 포함한다.
5. 조명을 정리한 고해상도 바탕에 계산 마스크를 적용했다. 과도한 선명화 필터는 사용하지 않았다.

## 검수

- 최종 크기와 RGB 8bit, 불투명 출력 확인.
- 새 해상도에서 직사광 시작 목표 **y784.595**, 마스크 50% 경계 **y784**. 오차 약 **0.595px**.
- 중앙 창틀의 차폐, 양쪽 채광, 뒤쪽 바닥의 직사광 부재 확인.
- 바닥 표본 영역의 미세 변동량은 원본 작업 바탕보다 약 **69.7% 감소**했다. 이는 원래 해상도에서 회색조와 1px 블러의 평균 절대차로 측정한 질감 변화이며, 잡티만 분리해 측정한 객관적 화질 점수는 아니다.
- 전체 화면에서 새 큰 잔상이나 구조 변형이 없는지 확인했다.
