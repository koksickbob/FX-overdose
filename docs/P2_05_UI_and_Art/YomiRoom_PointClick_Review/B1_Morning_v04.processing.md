## 적용 내용

1. 기존 바닥에 잘못 그려진 빛과 창틀 그림자의 명암을 정리했다. 국소 중간값을 기준으로 큰 명암과 세부 나뭇결·이음새를 분리하고, 그림자가 없는 주변 바닥색으로 간접광 바탕을 근사 복원했다.
2. 이전 직사광 경계의 작은 밝은 모서리 잔상을 정리했다.
3. 계산된 창 투영 다각형과 중앙 창틀 차폐 영역을 4배 크기에서 래스터화하고 원래 해상도로 내린 뒤 약 2px의 경계 부드러움을 적용했다.
4. 광원 마스크를 바닥 범위와 교차시켜 합성했다. 창 위쪽 블라인드 그림자는 이 모델에서 화면 아래에 있으므로 현재 바닥에 수평 그림자 줄을 추가하지 않았다.
5. 양측 벽에는 직사광 패턴을 추가하지 않았다. 램프는 아침 상태인 켜짐을 유지했다.

- 최종 이미지 x700~819의 실제 평균 밝기 상승 경계도 y682~684에서 확인했다. 블러와 바닥 널판의 명암 때문에 최댓값 표본은 y682다.

## 적용 범위와 남은 확인

남동향 창, 북위 37°, 춘추분, 현지 태양시 09:00이라는 **제작용 가정** 아래 창과 주요 창틀 투영을 맞췄다. 원본에 그려진 조명의 제거는 근사 복원이며, 상세한 블라인드 각도·창턱 깊이·화분 잎까지 재구성한 3D 물리 렌더링은 아니다.

방 구도의 기준은 채택된 v02, 후처리 입력은 v03이다. v02와 v03 사이의 모든 선이 픽셀 단위로 같다는 보장은 이 후처리 검수에 포함하지 않는다. 최종 시간대 공통 1920×1080 내보내기와 가구 레이어 합성은 아직 진행하지 않았다.

점심은 같은 태양 경로의 정오(고도 53°, 방위각 180°) 계산을 완료했다. 아침 컨펌 후 왼쪽 창 가까운 바닥의 짧은 직사광과 작은 측벽 접촉부, 상단 블라인드 그림자를 적용할 예정이다.
