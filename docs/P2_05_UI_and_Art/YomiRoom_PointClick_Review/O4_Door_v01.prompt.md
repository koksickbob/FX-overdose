# O4 문 v01 — 배치 재검토로 보류

- 도구: 내장 `image_gen`
- 출력: [O4_Door_v01.png](O4_Door_v01.png)
- 실제 규격: 1672×941, PNG, RGB 8bit. **체크무늬가 이미지에 그려져 있으며 실제 알파 채널이 없다.**
- 상태: **미채택, 배치 재검토로 보류. 게임 레이어로 사용할 수 없다.**
- 육안 검수: 문 자체가 요청 영역보다 크게 생성되어 침대·탁자 영역과 겹친다. 닫힌 문 디자인 외에 크기·원근·투명도는 보완이 필요하다.
- 후속 기준: [배치 재검토 v01](Layout_v01.md). 일반 이미지 후처리 사용 여부에 대한 사용자 답변은 받지 않았다.
