## 1. 물량을 줄이는 두 규칙

발주 전에 이 둘을 합의하면 작업량이 절반 아래로 떨어진다.

### 규칙 1 — B루트 배경은 재제작이 아니라 그레이딩이다

기준 문서의 B루트 연출 원칙은 **"이미 열려 있던 장소들이 색이 바랜 부정적 버전으로 교체"**다. 같은 원화에 채도·명도 그레이드만 다르게 적용한다.

- 대상 10곳 — 작은공원 · 만화카페 · 보드게임카페 · 코인노래방 · 꽃집(4-B) / 편의점 · 무인가게 · 코인세탁소 · 산책로(5-B) / 전시관
- **런타임 셰이더 그레이드로 처리하는 것을 우선 검토한다.** 파일을 두 배로 늘리지 않아도 되고, 맵 UI의 무채색 전환(D3 §3.3)과 같은 방식으로 통일된다.
- 톤이 부족하면 그때 개별 PNG를 뽑는다. 처음부터 뽑지 않는다.

### 규칙 2 — 계절 variant는 실제로 필요한 곳만

챕터가 계절을 따라가지만(여름–가을 → 겨울 → 봄 → 여름), **대부분의 장소는 한 챕터에만 등장한다.** 그 장소의 계절은 원화에 그냥 그려 넣으면 끝이다.

계절이 실제로 바뀌는 곳은 **B루트에서 재등장하는 1단계 장소 4곳뿐**이다 — 원래 여름–가을인데 챕터 5-B에서 봄에 다시 나온다.

| 장소 | 1차 등장 | B루트 재등장 | 처리 |
| --- | --- | --- | --- |
| 편의점 · 무인가게 · 코인세탁소 | 여름–가을 | 봄 (5-B) | **실내**라 계절이 창밖뿐 → 그레이딩으로 흡수, 추가 원화 없음 |
| 산책로 | 여름–가을 | 봄 (5-B) | **야외**라 흡수 불가 → **봄 variant 1장 추가** |
| 작은공원 · 만화카페 · 보드게임카페 · 코인노래방 | 겨울 | 늦겨울 (4-B) | 같은 계절 → 추가 없음 |

## 3. 연속성 소품

진엔딩에서 회수되는 장치다. **디자인을 먼저 고정하고 각 장면에 같은 그림을 넣는다.**

| 소품 | 첫 등장 | 회수 |
| --- | --- | --- |
| 무드등 | 챕터2 [집-잠] | 챕터4 [집-혼자있는밤] |
| 화분 | 챕터2 [꽃집-1] → 챕터3 화분 → 챕터4 요미가 직접 고른 화분 | **진엔딩 #2 창가의 화분** — 첫 화분과 같은 종으로 그린다 |
| 즉석사진 | 챕터4 [한옥마을-즉석사진관] | 냉장고에 붙어 있는 상태로 재등장 |
| 반지 | 챕터5 [반지공방-1] | **진엔딩 #12** — 요미가 직접 만든 것이므로 **모양이 삐뚤어야 한다** |
| 스케치북 | 챕터5 [집-스케치북] | 진엔딩의 그림 그리는 요미 |
| 식은 커피 | — | 진엔딩 #4. 시간 경과를 대사 없이 보여주는 장치 |

## 4. 전망대 ↔ 진엔딩 구도 고정 (최우선 제약)

진엔딩 #19의 구도는 **CP4 전망대 씬과 정확히 동일해야 한다.** 유리에 닿은 손끝이 그 장면 내내 반복 노출되어 플레이어가 마지막 컷에서 알아보는 **앵커**가 되기 때문이다. 어긋나면 엔딩의 마지막 반전이 성립하지 않는다.

- **전망대 배경과 진엔딩 CG는 같은 작업 묶음으로 발주한다.** 다른 시점에 다른 사람이 그리면 반드시 어긋난다.
- 진엔딩 #3·#4는 화면 내용을 **절대 보여주지 않는 것**이 전제이며 #18에서 처음 공개된다. 구도 설계 시 화면이 가려지는 앵글이어야 한다.
