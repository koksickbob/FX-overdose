# P2_01: 요미의 방 아키텍처

## 개요
Phase 2 게임 루프의 메인 허브인 '요미의 방' 시스템 구조를 정의합니다.

## 핵심 로직
- **행동 선택**: 월드맵 이동 / 요미와 자유 대화 / 휴식 / 트레이딩 시작
- **로딩 분기**: 
  - 방 내부 자유 대화/휴식: 로딩 없음
  - 월드맵/트레이딩/데이트 이동 시: `LoadingSceneManager` 호출

## 관련 스크립트 (예정)
- `YomiRoomManager.cs`: 요미의 방 상태 전이를 담당하는 로직 컨트롤러.
- `YomiRoomUIController.cs`: UI 버튼 및 텍스트 갱신 뷰 컨트롤러.
