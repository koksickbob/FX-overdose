# [FX Overdose] 동적 시간 완급 조절 및 슬로우 모션 연출 기획서 (Solution #3)

---

## 📌 1. 개요 및 기획 배경
현재 `FX Overdose`의 인게임 시간 흐름은 **현실 시간 8분(1분 = 현실 1.0초) = 인게임 24시간**으로 고정되어 있습니다.
이로 인해 주가 차트, 체력, 멘탈, 포지션 수익률(ROE)이 매우 긴박하게 요동치며, 여러 이벤트가 동시다발적으로 발생할 때 AI 대사가 이를 전부 따라가지 못하거나 대기 큐에서 만료되는 현상이 발생합니다.

현재 적용 완료된 **1번(대사 출력/쿨타임 단축)** 및 **2번(상태 스냅샷 종합 보간)** 솔루션을 통해 대사 적체 문제는 대폭 해결되었으나, 추후 **극적인 연출 극대화 및 플레이어의 몰입감 강화**를 위해 인게임 시간 속도를 상황에 따라 동적으로 가속/감속하는 **'영화적 완급 조절(Dynamic Time Regulation & Slow-Motion Directing)' 시스템** 도입을 계획합니다.

## 💡 2. 핵심 설계 개념

### ① 국면별 시간 속도 동적 변동 (Adaptive Time-Scale)
`GameManager.SecondsPerGameMinute` (기본값 1.0초 = 게임 내 1분)를 고정하지 않고, 시장 국면(`MarketRegime`)과 포지션 보유 상태에 따라 유동적으로 조절합니다.

| 게임 내 상황 / 시장 국면 | 목표 `SecondsPerGameMinute` | 현실 1분당 흐르는 게임 시간 | 연출 목적 및 기대 효과 |
| :--- | :---: | :---: | :--- |
| **차트 평화 / 관망 구간**<br>(포지션 없음 & `Sideways`) | **0.5초** (2배 가속) | 120분 (2시간) | 지루한 횡보 구간 빠르게 패스, 긴장감 압축 |
| **일반 매매 및 추세 진행**<br>(포지션 보유 & 일반 변동) | **1.0초** (기본 속도) | 60분 (1시간) | 표준 거래 속도 유지 및 AI 일반 판단 |
| **위기 및 변곡점 도달**<br>(ROE ±25% 이상 / 청산 위기) | **2.0초 ~ 3.0초** (감속) | 20~30분 | **슬로우 모션 긴장감 유도**, 중요 대사 필독 시간 확보 |
| **폭주 / 광기 스퀴즈**<br>(`Squeeze` 국면 / `Overdose` 상태) | **0.3초 ↔ 3.0초** (극적 교차) | 불규칙 펄스 | 극도의 카오스 연출 (주가 폭주 시 가속 ↔ 청산 빔 직전 극적 감속) |

## ⚙️ 3. 상세 시스템 구현 계획

### 1) `DynamicTimeRegulator` 컴포넌트 신설
- `GameManager` 또는 코어 시스템에 부착되어 매 프레임 `Time.unscaledDeltaTime`을 기반으로 목표 시간 배속(`TargetSecondsPerMinute`)을 부드럽게 보간(`Mathf.Lerp`)합니다.
- 주가 틱 변동 속도(`MarketSimulationEngine.tickInterval`)와 AI 대사 최소 보장 시간(`AIVisualController.minReadDuration`)이 이 변동 배속과 자동으로 연동되어 **차트 속도와 대사 출력 속도가 완벽히 동기화**됩니다.

### 2) 주요 트리거 이벤트 (Slow-Motion Triggers)
다음 상황 발생 시 즉각 `DynamicTimeRegulator.SetSlowMotion(duration, factor)`를 호출합니다:

1. **강제 청산 마진콜 임박 (Margin Call Danger Window)**
   - **조건**: 포지션 증거금 소진율 80% 도달 (청산까지 주가 여유 0.5% 미만)
   - **연출**: 시간 속도가 3배 감속(`SecondsPerGameMinute = 3.0s`)되며 화면 가장자리에 붉은 경고 오라가 점멸. AI의 긴급 구출 요청 대사(`"마스터, 제발!! 지금 손절 안 하면 전부 털려!!"`)가 화면 정중앙이나 상단 우선순위로 출력.
2. **초대박 돌파 및 목표가 달성 직전 (Target Price Breakthrough)**
   - **조건**: AI 설정 목표가(`Target Price`) 도달 10초 전 또는 ROE +50% 돌파
   - **연출**: 시간 2배 감속과 함께 화려한 골드 오라 파티클 재생. AI의 환호성 대사 충분한 감상 시간 확보.
3. **멘탈 오버도즈 폭주 발동 순간 (Overdose Awakening)**
   - **조건**: `TraderStatus.CurrentMentalState == Overdose` 진입 순간
   - **연출**: 단 3초간 시간이 0.2배속(초슬로우)으로 멈추듯 느려지며, 캐릭터 애니메이터의 광기 표정 컷인(Cut-in) 애니메이션과 폭주 선언 대사 재생 후, 4배 가속으로 풀레버리지 매매 돌입.

## 📐 4. 예상 코드 아키텍처 개요 (`DynamicTimeRegulator.cs`)

```csharp
namespace FXOverdose.Core
{
    public class DynamicTimeRegulator : MonoBehaviour
    {
        [SerializeField] private GameManager gameManager;
        [SerializeField] private float baseSecondsPerMinute = 1.0f;
        private float targetSecondsPerMinute = 1.0f;
        private Coroutine slowMotionCoroutine;

        private void Update()
        {
            if (gameManager == null || gameManager.CurrentState != GameManager.GameState.Playing) return;

            // 부드러운 시간 배속 전환 (Lerp)
            float current = gameManager.SecondsPerGameMinute;
            gameManager.SetSecondsPerGameMinute(Mathf.Lerp(current, targetSecondsPerMinute, Time.deltaTime * 3f));
        }

        public void TriggerDramaticSlowMotion(float targetSpeed, float durationSeconds)
        {
            if (slowMotionCoroutine != null) StopCoroutine(slowMotionCoroutine);
            slowMotionCoroutine = StartCoroutine(SlowMotionRoutine(targetSpeed, durationSeconds));
        }

        private IEnumerator SlowMotionRoutine(float targetSpeed, float duration)
        {
            targetSecondsPerMinute = targetSpeed;
            yield return new WaitForSecondsRealtime(duration);
            targetSecondsPerMinute = baseSecondsPerMinute;
        }
    }
}
```
