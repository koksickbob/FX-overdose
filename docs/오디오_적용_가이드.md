# FX OVERDOSE 오디오 적용 가이드

이 문서는 제작이 완료된 효과음과 BGM을 프로젝트에 넣는 작업자를 위한 가이드입니다. 현재 오디오 시스템은 파일 경로와 이름을 기준으로 자동 연결되므로 Unity 인스펙터에 오디오 파일을 직접 등록할 필요가 없습니다.

## 1. 적용 순서

1. 전달받은 오디오가 `WAV` 형식인지 확인합니다.
2. 아래 경로표에 맞는 폴더에 파일을 넣습니다.
3. 파일 이름을 경로표와 완전히 동일하게 변경합니다.
4. Unity를 열거나 Project 창으로 돌아가 임포트가 끝날 때까지 기다립니다.
5. 타이틀부터 게임을 실행해 해당 기능의 소리가 재생되는지 확인합니다.

권장 출력 형식은 `48 kHz`, `24-bit WAV`입니다. Unity가 지원하는 다른 형식도 사용할 수 있지만, 팀 작업에서는 음질과 관리 규칙을 통일하기 위해 WAV를 권장합니다.

## 2. 중요 규칙

- 파일명은 영문 소문자와 밑줄만 사용합니다.
- 아래 표에 적힌 파일명을 임의로 변경하지 않습니다.
- 같은 이름의 기존 파일이 있으면 교체 대상이 맞는지 먼저 확인합니다.
- 파일 경로는 반드시 `Assets/Resources/Audio` 아래여야 합니다.
- Unity 인스펙터의 `AudioManager` 슬롯에 파일을 드래그하지 않습니다.
- 오디오 앞부분의 불필요한 무음과 끝부분의 긴 잔향을 제거합니다.
- BGM과 동적 레이어는 반복 경계에서 끊김이 없는 루프 파일을 사용합니다.
- 오디오 파일과 Unity가 생성한 `.meta` 파일을 함께 Git에 반영합니다.

파일이 없거나 이름이 잘못된 항목은 게임에서 오류를 발생시키지 않고 조용히 건너뜁니다. 따라서 소리가 나지 않을 때는 가장 먼저 파일명과 폴더 위치를 확인해야 합니다.

## 4. BGM 파일 경로

| 기능 | 파일 경로 |
|---|---|
| 평상시 BGM | `Assets/Resources/Audio/BGM/bgm_normal.wav` |
| 오버도즈 BGM | `Assets/Resources/Audio/BGM/bgm_overdose.wav` |
| 수익 우세 레이어 | `Assets/Resources/Audio/BGM/layer_profit.wav` |
| 위기 레이어 | `Assets/Resources/Audio/BGM/layer_danger.wav` |

`layer_profit.wav`와 `layer_danger.wav`는 `bgm_normal.wav` 위에서 동시에 재생됩니다. 세 파일은 다음 조건을 동일하게 맞춰야 합니다.

- BPM
- 전체 재생 길이
- 박자와 마디 시작점
- 루프 시작과 종료 지점
- 가능하면 동일한 샘플레이트

길이가 다르거나 시작점이 어긋나면 게임을 오래 실행할수록 리듬이 어긋날 수 있습니다.

## 5. Unity 임포트 권장 설정

Project 창에서 오디오 파일을 선택한 뒤 Inspector에서 아래 항목을 확인합니다.

### 짧은 효과음

- `Load Type`: `Decompress On Load`
- `Compression Format`: `PCM` 또는 `ADPCM`
- `Force To Mono`: 공간감이 필요 없는 UI 효과음이라면 활성화 가능
- `Preload Audio Data`: 활성화

### BGM과 긴 루프

- `Load Type`: `Streaming`
- `Compression Format`: `Vorbis`
- `Quality`: 우선 `70~85` 범위에서 확인
- `Preload Audio Data`: 프로젝트 메모리 상황에 따라 결정

플랫폼별 설정을 덮어쓸 때는 모든 BGM과 레이어에 같은 샘플레이트 정책을 사용합니다.

## 6. 테스트 체크리스트

오디오를 적용한 뒤 다음 항목을 확인합니다.

- [ ] 타이틀의 새 게임, 불러오기, 설정, 종료 및 팝업 버튼에서 클릭음이 난다.
- [ ] LONG과 SHORT의 수동·자동 진입음이 서로 구분된다.
- [ ] 포지션 종료 시 실제 PNL에 따라 수익음 또는 손실음이 난다.
- [ ] 레벨업과 스킬 레벨업 효과음이 중복 없이 한 번 재생된다.
- [ ] 아이템을 실제로 소비했을 때만 해당 아이템 효과음이 난다.
- [ ] 구매 성공 시 구매음이 나고 잔액 부족 시 부족음이 난다.
- [ ] 돌발 이벤트 UI가 등장할 때 효과음이 난다.
- [ ] 일일 결산 결과가 양수면 수익음, `0` 이하면 비수익음이 난다.
- [ ] 오버도즈 진입 시 효과음과 전용 BGM 전환이 작동한다.
- [ ] 게임 오버 시 게임 오버 효과음이 난다.
- [ ] 중요한 효과음이 재생될 때 BGM이 잠시 낮아진다.
- [ ] 수익과 위기 상태가 변할 때 동적 레이어가 부드럽게 증감한다.
- [ ] BGM을 장시간 재생해도 루프 경계에서 클릭이나 공백이 없다.
- [ ] 대사와 UI 효과음이 BGM에 묻히지 않는다.

## 7. 소리가 재생되지 않을 때

다음 순서로 확인합니다.

1. 파일이 정확한 폴더에 있는지 확인합니다.
2. 대문자, 띄어쓰기, 하이픈을 포함해 파일명이 표와 다른지 확인합니다.
3. 확장자가 이중으로 붙지 않았는지 확인합니다. 예: `profit.wav.wav`
4. Unity의 오디오 임포트가 완료되었는지 확인합니다.
5. Console에 오디오 임포트 오류가 있는지 확인합니다.
6. Game 뷰의 `Mute Audio`가 활성화되어 있지 않은지 확인합니다.
7. 게임 설정의 Master, BGM, SFX 볼륨이 `0`이 아닌지 확인합니다.
8. 해당 동작이 실제로 성공했는지 확인합니다. 구매 실패나 아이템 사용 실패에는 성공 효과음이 재생되지 않습니다.
9. Play Mode 중 파일을 추가했다면 Play Mode를 종료하고 다시 실행합니다.

## 8. 파일 교체 방법

기존 오디오를 새 버전으로 교체할 때는 같은 경로와 파일명을 유지한 채 파일 내용만 교체합니다. Unity 밖에서 교체했다면 기존 `.meta` 파일은 삭제하지 않습니다. `.meta`를 유지하면 Unity 에셋 GUID가 바뀌지 않아 협업 중 불필요한 변경을 줄일 수 있습니다.

교체 후에는 반드시 해당 효과음뿐 아니라 다음 항목도 함께 확인합니다.

- 다른 소리보다 지나치게 크거나 작지 않은가
- 끝부분 잔향이 다음 효과음과 겹치지 않는가
- 중요 효과음 재생 시 덕킹이 자연스러운가
- BGM 루프와 레이어의 싱크가 유지되는가

## 9. 새 오디오 항목을 추가할 때

표에 없는 완전히 새로운 효과음을 추가하려면 파일만 넣어서는 자동 연결되지 않습니다. 다음 코드 변경이 함께 필요합니다.

1. `Assets/Scripts/System/AudioManager.cs`의 `AudioCue`에 새 항목을 추가합니다.
2. 같은 파일의 `CuePaths`에 Resources 경로를 등록합니다.
3. 실제 게임 이벤트가 성공한 지점에서 `AudioManager.Play(...)`를 호출합니다.
4. 이 가이드와 `docs/오디오.md`의 경로표를 갱신합니다.
5. Unity C# 빌드와 실제 재생 테스트를 진행합니다.

기획과 AI 생성 프롬프트는 [오디오.md](오디오.md)를 참고합니다.
