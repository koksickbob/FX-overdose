# A. 낡은 목표 문구 최신화

## A-1. 현재 엔딩 조건 (코드 확인 결과)

문구를 고치려면 먼저 "지금의 진짜 목표"가 무엇인지 확정해야 합니다. 코드 상태는 이렇습니다.

| 엔딩 | 실제 발동 조건 | 위치 |
| --- | --- | --- |
| **Success** | **20일차 최종 보스(사채업자)를 자산으로 격파** | [GameManager.cs:704-707](../../Assets/Scripts/GameManager.cs#L704) |
| Success (백업) | 20일차에 보스가 없을 때 `총자산 >= $1,000,000` | [L737-741](../../Assets/Scripts/GameManager.cs#L737) |
| Overdose | 총자산·현금 모두 0 이하 **＋ 멘탈 0** / 보스전 패배 | [L1077](../../Assets/Scripts/GameManager.cs#L1077) · [L730](../../Assets/Scripts/GameManager.cs#L730) |

> 즉 **"100만 달러 달성"은 더 이상 승리 조건이 아니고**, 승리는 **최종 보스 격파**입니다.
> 보스 자산은 `그날 아침 자산 × 0.9`라 절대 금액 목표가 아니라 **상대 평가**입니다.

## B-3. 발동 지점

`currentState = GameState.Playing` 전이가 **6곳**에 흩어져 있어(보스 연출·스토리 컷씬·로드·취침 복귀 등) 그 전부에 거는 것은 취약합니다.

**`AdvanceOneMinute()`에서 하루 1회 지연 발동**을 제안합니다.

```csharp
private int expenseAnnouncedForDay = -1;
...
// AdvanceOneMinute 안, OnGameMinuteAdvanced 발행 이후
if (expenseAnnouncedForDay != currentDay)
{
    expenseAnnouncedForDay = currentDay;
    AnnounceTodayExpenses();
}
```

이 지점은 **모든 아침 연출이 끝나고 시간이 실제로 흐르기 시작한 뒤**에만 도달하므로,
보스 등장 연출이나 스토리 컷씬과 말풍선이 겹치지 않습니다. 6곳을 찾아다닐 필요도 없습니다.

## B-4. 대사 내용 (초안)

`AIVisualController.DisplayDialogueBalloon(text, DialoguePriority.High, EventCategory.General)`로 출력합니다.

| 상황 | 초안 |
| --- | --- |
| 정기 지출만 | *"오빠, 오늘 밤에 {사유}로 ${금액} 빠져나가. 그 전에 벌어놔야 해!"* |
| 위약금만 | *"오늘 밤 위약금 ${금액} 나가는 날이야... 각오하고 시작하자."* |
| 둘 다 (11일차) | *"오늘 최악이야... {사유} ${A}에 위약금 ${B}까지, 합쳐서 ${A+B}이 밤에 빠져나가!"* |
| 지출 없음 | 출력 안 함 |

> 문구는 코드에 리터럴로 둡니다. 금액·사유가 동적이라 `YomiDialogueDatabase`에 그대로 넣을 수 없고,
> 매처의 치환 태그(`{leverage}`/`{margin}`/`{roe:F1}`)에는 금액·사유용이 없기 때문입니다.
> 나중에 작가가 변형을 쓰고 싶어지면 그때 `{deduction}`/`{reason}` 태그를 추가하는 편이 낫습니다(선지출 금지).
