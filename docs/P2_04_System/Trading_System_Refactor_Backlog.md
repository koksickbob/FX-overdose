## 2. 의존성

화살표는 "선행 → 후행"입니다. **선행을 건너뛰면 후행이 의도대로 동작하지 않습니다.**

```
SIG-0  ──┬──► SIG-A4   (셋업 10종: AI switch 4개를 먼저 Direction으로 치환해야 함)
         └──► SIG-B1   (궤적 에셋화)

FIX-1  ─────► FIX-4    (가격이 이어지면 H4·D1이 자동으로 채워짐)

FIX-2  ─────► SIG-B7   (꼬리가 청산을 유발해야 shakeout이 실제 위협이 됨)

SIG-B3 ─────► SIG-B8   (되돌림이 자연스러워진 뒤라야 노이즈 완화 충격이 줄어듦)

DEAD-3 ─────► SIG-A4   (빈 리액션을 걷어 두고, 필요하면 셋업별 반성 대사로 새로 구독)

DEL-2  ─────► REAL-1   (정기 지출이 비운 장기 압박을 펀딩비로 대체)

SIG-B5 ──╌╌─► REAL-6   (점선: B5가 R6의 80%를 선취 — R6 우선순위를 낮출 수 있음)
REAL-7 ──╌╌─► FIX-3(a) (점선: 변동성 재조정 전에는 일차 배수를 곱하면 안 됨)
```

**독립 항목** (아무 때나 가능): FIX-3(b), FIX-7, FIX-8, DEAD-1, DEAD-2, DEAD-6, SIG-A1, SIG-A2, SIG-A5, SIG-A7, SIG-B2, SIG-B4, SIG-B6, REAL-4, REAL-5
