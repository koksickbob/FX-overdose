## 1. 확정 테이블

| 티어 | 호감도 | 관계 단계 이름 | 한 줄 정의 |
| --- | --- | --- | --- |
| **T1** | **0 ~ 30** | 서먹 | 같이 살지만 아직 조심스럽다. 시선을 잘 못 맞추고 반 발짝 물러서 있다 |
| **T2** | **31 ~ 60** | 일상 | 편해졌다. 투정·장난·삐짐이 자연스럽게 나온다 |
| **T3** | **61 ~ 90** | 애정 | 마음이 겉으로 샌다. 홍조가 잦고 몸이 화면(오빠) 쪽으로 기운다 |
| **T4** | **91 ~ 100** | 전면화 | 세계가 오빠 하나로 축소된다. 시선 고정, 거리 제로. **수위는 애원·응석까지 — 공포 연출 금지** |

**경계값은 91이다.** 호감도 90은 **T3**다. 기존 P2_07 문서의 `90+` 표기는 상한·하한이 모호했고, 이 문서로 **91+로 확정**한다 (P2_07 쪽 표기도 함께 수정됨 — 6장).

호감도는 `DatingTimeManager.ModifyAffection()`에서 **0~100으로 클램프**되므로 (SV-B12) 티어 밖의 값은 존재하지 않는다.

## 2. 판정 규칙

**경계는 하나, 판정 입력값은 용도에 따라 둘이다.** 이 구분은 이미 각 시스템에 의도적으로 설계돼 있으며, 이 문서로 공식화한다:

| 규칙 | 내용 | 근거 |
| --- | --- | --- |
| **해금 판정 = 역대 최고치** | 토픽 해금 등 **잠금성 콘텐츠**는 `TalkPeakAffection`(peak)으로 판정한다. 티어는 오르기만 한다 | 호감도가 깎여도 이미 열린 화제가 되감기면 안 된다 (TS8) |
| **연출 판정 = 현재치** | 감정 스프라이트 등 **표현·연출**은 `DatingTimeManager.CurrentAffection`으로 판정한다. 티어가 내려갈 수 있다 | 연출은 지금의 관계 온도를 비춰야 한다. 호감도가 깎였는데 T4 표정이 나오면 거짓말이 된다 (P2_07 파급 분석) |
| **경계값의 출처** | **코드 상수.** 세이브에 저장하지 않는다 | 저장하면 이중 진실 원천이 된다 (기존 8.4절 원칙) |
| **토픽 상한(`MaxAffection`)** | T4에서도 기존 토픽을 **닫지 않는다** (전부 100 유지) | "밥 먹었어?"는 T4에서도 성립한다. 본 적 없는 토픽을 영영 못 보는 사고 방지 (8.2절 결정 유지) |

> 신규 시스템이 티어를 참조할 때의 선택 기준: **"한 번 보여준 것을 되감으면 이상한가?"** — 이상하면 peak(해금형), 지금 상태를 비추는 것이면 현재치(연출형).

**코드 상수화 지침** (T4 토픽 구현 시 함께):

```csharp
// YomiTalkTopics.cs 등에 — 경계가 세 파일에 숫자로 흩어지는 것을 막는다
public static class AffectionTier
{
    public const int T2Min = 31;
    public const int T3Min = 61;
    public const int T4Min = 91;   // T4 신설 (2026-08-14). 90은 T3다.
}
```

## 3. ⚠️ 명칭 충돌 정리 — "티어"가 세 개다

이 프로젝트에는 "티어/구간"이라는 말이 서로 다른 세 축에 쓰이고 있다. **혼용이 이미 한 번 사고를 냈다** (P2_07의 `90+` 모호 표기). 아래처럼 부른다:

| 축 | 정식 명칭 | 값 | 절대 헷갈리면 안 되는 이유 |
| --- | --- | --- | --- |
| 호감도 | **호감도 티어 T1~T4** (이 문서) | 0/31/61/91 경계 | 화제·연출·스프라이트가 걸림 |
| 차트 힌트 | **힌트 티어 1·2** (모호/명시) | 당일 대화 획득 2/3점 임계 | `HINT_BULL_T2_03` 같은 **대사 ID의 "T2"는 힌트 티어다.** 호감도 T2와 무관. ID는 세이브(`TalkHintLineId`)에 기록되므로 **개명 금지** |
| 집착도 | **집착도 구간** (바이블 5.3절) | 0~30 / 31~60 / 61~85 / **86~100** | 경계 자체가 다르다(85/86). 호감도는 *무슨 얘기를 하는지*, 집착도는 *얼마나 세게 말하는지* — 축이 다르다 |

**문서·커밋·대화에서 호감도 구간을 말할 때는 반드시 "T1~T4"를 쓴다.** "1단계/2단계" · "구간 1" 같은 표기는 이 문서로 폐기한다.

## 5. 도달 가능성 산수 — T4 설계 전제

자유 채팅의 하루 호감도 획득 상한은 **+3**이다 (14장 개편). 대화만으로 각 티어에 닿는 데 걸리는 최소 일수:

| 목표 | 필요 호감도 | 대화만으로 최소 일수 |
| --- | --- | --- |
| T2 진입 | 31 | 11일 |
| T3 진입 | 61 | 21일 |
| **T4 진입** | **91** | **31일** |

게임 기준 길이가 약 20일이므로 **대화만으로는 T4에 도달할 수 없다. 이것은 버그가 아니라 설계 전제다** — T4는 데이트·이벤트 등 대화 외 호감도 공급원을 병행한 플레이어에게만 열리는 구간이다. 데이트 보상 설계 시 이 산수를 기준으로 잡는다 (예: 데이트 1회 +5면 대화 병행 시 약 12일 차 T4 진입).

> 반대로 대화 외 공급원이 아직 없는 현재 빌드에서는 **T4 콘텐츠가 보이지 않는 것이 정상**이다. QA에서 "T4 토픽이 안 나온다"는 보고가 오면 먼저 이 표를 확인할 것.
