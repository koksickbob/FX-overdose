# 📉 요미의 20일 떡상 프로젝트: 스토리 모드 총괄 기획서 (마스터본 - 시스템 개발 특화)

본 문서는 극한의 난이도를 자랑하는 '요미의 20일 떡상 프로젝트' 스토리 모드를 완벽하게 구현하기 위한 최종 마스터 기획서입니다. 
아트 파트(만화 제작)는 아트 디렉터님께 위임되었으므로, **본 기획서는 완성된 아트 애셋이 도착하는 즉시 게임에 연동(플러그인)할 수 있는 '시스템 기반'을 구축하는 데 집중**합니다.

---

## 1. 🎯 핵심 컨셉 및 게임 목표 (Core Concept)
**"단 20일! 전 재산 4,000달러로 100만 달러 만들기 초단기 극악 챌린지!"**
알바에서 잘리고 수중에 남은 $4,000를 들고 FX 마진 거래에 모든 것을 건 허당 요미. 20일이라는 제한된 시간 동안 거래(익절)를 통해 경험치를 쌓아 주인공 레벨을 올리고, 해금되는 엄청난 레버리지(최대 100배)를 끌어다 쓰며 자산을 폭발적으로 불려야 합니다. 동시에, 스트레스로 인해 멘탈 수치가 0이 되어 쓰러지지 않도록 철저히 관리해야 하는 하드코어 모드입니다.

---

## 2. ⏳ 스토리 진행 및 단계별 목표 (Phases)
플레이어의 실력과 운에 따라 레벨/자산 편차가 극심하게 갈리기 때문에, 아래의 각 Phase별 목표는 **'살아남기 위한 권장 가이드라인'**의 역할을 합니다. (조기 달성하더라도 게임은 끝나지 않으며 끝까지 버텨야 합니다.)

* **Phase 1: 근자감의 시작 (Day 1 ~ Day 5)**
  * **생존 권장 레벨:** 최소 LV.4 (최대 20배 레버리지) 달성.
  * **목표:** 초반 5배 레버리지 제한 속에서, 잦은 소액 익절을 통해 주인공 경험치를 모아 빠른 레벨업을 달성해야 합니다. 여기서 레벨업이 지연되면 스노우볼이 굴러가 이후 페널티를 막기 매우 힘들어집니다.
  * **페널티 이벤트 (Day 5):** 밀린 월세 강제 집행 (-$10,000)
* **Phase 2: 욕망과 멘탈 붕괴 (Day 6 ~ Day 15)**
  * **생존 권장 레벨:** LV.9 (최대 100배 레버리지) 해금 완료.
  * **목표:** 해금된 중고배율 레버리지를 활용하여 자산을 공격적으로 뻥튀기합니다. 초고수 플레이어는 이 시점에 이미 $1M을 찍을 수도 있지만, **목표를 달성해도 Day 20까지 자산과 멘탈을 갉아먹는 페널티들을 버텨내야만 합니다.**
  * **이벤트:** Day 6 타락 컷씬 재생 / Day 11 사채업자 이자 청구 (-$30,000)
* **Phase 3: 운명의 일주일 (Day 16 ~ Day 20)**
  * **레버리지 현황:** LV.9 이상 (최대 100배)
  * **목표:** 10만 달러 위약금을 내고 반토막 난 자산으로 100배 풀레버리지를 활용해 최후의 100만 달러 고지를 밟고, Day 20까지 수비하기.
  * **이벤트:** Day 16 망가진 커피 머신과 손님의 고급 의류 배상 청구서 폭탄 (-$100,000) 및 클라이맥스 컷씬.

## 3. 🏆 스토리 모드 클리어 (진 엔딩) 3대 조건
아래 **A, B, C 조건을 모두 완벽하게 충족**한 상태로 Day 20 정산을 마쳐야 진 엔딩 처리됩니다. 중간에 일찍 100만 달러를 달성해도 조기 클리어는 없습니다.

> [!IMPORTANT]
> **최종 클리어 조건 (Day 20 정산 기준)**
* **조건 A:** 최종 순자산 $1,000,000 (100만 달러) 이상 달성
* **조건 B:** 최종 정산(Day 20) 시점, '멘탈 수치' 30% 이상 유지
* **조건 C:** 16일 차 10만 달러 위약금 폭탄을 맞고도 자산이 0 이하로 떨어지지 않고 생존

## 4. 📖 만화 연출 UI 시스템 구축 (아트 연동 준비)

아트팀에서 컷툰 이미지를 전달받는 즉시 게임에 띄울 수 있도록 확장 가능한 전용 뷰어 시스템을 선행 개발합니다. (개발 시점에서는 **임시 더미(Dummy) 이미지**를 넣어 로직을 테스트합니다.)

### 4-1. `ComicCutsceneController` (UI 기반 뷰어)
* **기능:** 씬 전환(Scene Load) 없이 기존 화면 최상단 Canvas에 팝업되어, 클릭 시 다음 만화 컷(Sprite)으로 슬라이드/페이드인 되는 전용 뷰어. 우측 상단 'Skip' 버튼 지원.
* **확장성:** `List<Sprite>`를 인자로 받아 동적으로 UI Image에 렌더링. 아트 애셋의 장수가 1장이든 4장이든 코드를 수정할 필요 없이 유연하게 처리합니다.

### 4-2. 진행 단계별 스토리 만화 (컷툰 연출)

**[Phase 1: 근자감의 시작]**
* **Day 1 (인트로 / 4컷):** 
  1. 커피를 손님에게 쏟아 점장에게 쫓겨나는 요미.
  2. 비 오는 거리에서 뱅킹 잔고('$4,000')를 보며 좌절.
  3. 전광판에서 FX 거래소 떡상 광고 목격.
  4. 노트북 앞에 앉아 차트를 켜는 요미의 결연한 표정.
* **Day 5 (1차 위기 / 2컷):** 
  * 문틈으로 '월세 집행장'이 들어옴 -> 계좌에서 돈(-$10,000)이 빠져나가 경악하며 땀을 흘리는 요미. (이게 장난이 아님을 깨달음)

**[Phase 2: 욕망과 멘탈 붕괴]**
* **Day 6 (Phase 2 시작 / 2컷):** 
  * "이 속도로는 100만 달러 어림도 없어!"라며 눈꺼풀에 테이프를 붙이고 에너지 드링크 탑을 쌓은 채 풀레버리지 버튼을 누르는 광기 어린 컷.
* **Day 11 (2차 위기 / 2컷):** 
  * 사채업자가 문을 열고 들어와 이자 청구서를 들이밈 -> 덜덜 떨며(-$30,000) 송금 버튼을 누르는 컷.

**[Phase 3: 운명의 일주일]**
* **Day 16 (클라이맥스 위기 / 3컷):** 
  1. 쾅! 소리와 함께 날아온 망가진 커피 머신과 손님의 고급 의류 배상 청구서(-$100,000).
  2. 잔고가 박살 나 영혼이 빠져나간 요미.
  3. 머리에 'To the Moon' 띠를 두르고, 피눈물을 흘리며 마지막 5일의 전투 모드에 돌입하는 각성 컷.

### 4-3. 엔딩 만화 (Day 20 이후 / 각 3~4컷)
* **[진 엔딩] 자본주의의 기적 (Success):** 잔고 100만 달러 확인 -> 펜트하우스에서 황금 선글라스를 끼고 돈비(Money Rain)를 맞는 요미.
* **[배드 엔딩 1] 파산 (Bankruptcy):** 잔고 0원 확인 -> 고시원에서 짐을 싸서 쫓겨남 -> 비 오는 날 박스를 덮고 알바 구인 앱을 켜는 씁쓸한 요미.
* **[배드 엔딩 2] 오버도즈 (Overdose):** 멘탈 폭발 -> 화면 밖 돈다발을 꽉 껴안음 -> 다크서클이 턱 끝까지 내려온 채 모니터만 보고 실성해 웃는 호러틱한 요미.

## 5. ⚙️ 코어 시스템 데이터 설계 (Code Implementation)

### 5-1. `GameManager.cs` 수정
* **다단계 스토리/위약금 템플릿 엔진 추가:**
  ```csharp
  [System.Serializable]
  public class StoryEvent 
  { 
      public int TriggerDay; 
      public bool IsPenalty; 
      public float PenaltyAmount; 
      public string DialogueMessage; 
      public List<Sprite> ComicPanels; // 아트팀에서 받은 이미지 할당용 슬롯
  }
  ```
* **이벤트 실행 로직:** 
  * `AdvanceOneMinute()` 내 24:00 도달 시, 오늘 자 이벤트(`TodayEvent`)가 등록되어 있다면 위약금을 강제 차감.
  * `TodayEvent.ComicPanels` 리스트에 이미지가 등록되어 있다면 `ComicCutsceneController`를 호출하여 만화 우선 재생.
* **20일 차 최종 분기:** `ProceedToNextDay()`에서 Day 20 엔딩 조건을 검사하고, 결과에 맞는 엔딩 컷툰(더미 이미지)을 띄우며 게임 오버 처리.

### 5-2. `DailySettlementUIController.cs` 수정
* **하드코딩 대사 통합:** LLM 호출 코루틴 제거 후 텍스트 즉시 출력 방식 적용.
* **페널티 텍스트 우선권:** 페널티 이벤트 날에는 정산 UI 배경 테두리를 붉은색(Danger)으로 점멸시키며, 페널티 템플릿 대사를 1순위로 출력.

## 6. 🚨 기존 시스템 충돌 방지 및 안전장치 (Conflict Prevention)

1. **지연된 게임 오버 (즉시 파산 방지):**
   * 24:00 위약금 차감 시 잔고가 0 이하가 되어도 즉시 파산시키지 않고(`isSettlementProcessing = true`), 컷툰 연출과 정산 UI를 모두 감상한 뒤 **'다음 날로 진행'을 누르는 순간** 파산 여부를 일괄 검사하여 유예시킵니다.
2. **오버도즈 무적 쉴드 오버라이드:**
   * 실시간 차트 중에 발동되는 오버도즈 35초 무적 쉴드(`IsOverdoseProtected`)는 24:00 일일 정산 시점에서는 무시됩니다. 파산 판정이 나면 쉴드를 뚫고 게임 오버(Bankruptcy) 처리.
3. **디데이(D-Day) 타이머 연동:**
   * 상단 시간 UI에 현재 날짜를 `DAY 01 / 20` 형식으로 표기하여 시스템적으로 타임어택 압박감을 관리.
