# 게임 업적 및 달성도 시스템 적용 내역

계획에 따라 코어 시스템 및 UI 연동 작업을 성공적으로 마무리했습니다! 이제 게임을 플레이하며 쌓인 데이터가 누적되고, 업적 달성 시 추후 코스튬(스킨)의 잠금 해제와 연동될 수 있는 강력한 기반이 마련되었습니다.

## 1. 전역 업적 시스템 구축
새로운 싱글톤 매니저 클래스 `AchievementManager.cs`를 구현했습니다.

*   **글로벌 저장소 활용:** `PlayerPrefs`를 사용하여 유저의 행동 데이터(아이템 사용 누적 횟수, 획득한 최고 자산, 달성한 엔딩, 레벨 등)를 계정 단위로 영구 보존합니다.
*   **다양한 타입 지원:** `AchievementType` Enum을 기반으로 복합적인 조건(아이템 ID 일치 여부, 자산 커트라인 등)을 처리할 수 있도록 추상화했습니다.
*   **업적 리스트 등재:** 기획된 14개의 주요 업적(엔딩 4종, 최고 자산 3단계, 카페인/당분 중독, 레벨업, 이벤트 성공 등)을 데이터베이스에 등록했습니다.

## 2. 게임 내 이벤트 추적 연동
다양한 스크립트에서 발생하는 이벤트를 `AchievementManager`가 수집하도록 보고(Report) 라인을 주입했습니다.

*   `GameManager.cs`: 자산이 변동될 때 최고 자산을 검사하고, 엔딩이 발생할 때마다 해당 엔딩을 기록합니다.
*   `ItemUser.cs`: 아이템(에너지 드링크, 파르페 등)의 효과가 발동했을 때 사용 횟수를 누적시키고, 특수 기믹인 '트라우마 극복' 시점을 감지해 보고합니다.
*   `ShopManager.cs`: 소모성 아이템 구매가 이루어지면 누적 구매 횟수를 올립니다.
*   `ChoiceEventController.cs`: 하이 리스크(Aggressive) 선택지를 골라 성공(isSuccess)했을 경우를 감지하여 '하이 리스크 하이 리턴' 업적에 횟수를 누적시킵니다.
*   `TraderLevelSystem.cs`: 주인공 트레이더 레벨이 오를 때마다 최고 레벨 도달 여부를 확인하여 마스터 업적을 달성시킵니다.

## 3. 상점 렌더링 및 보안(UI 연동)
`DynamicShopUI.cs`에 업적 달성 여부를 조회하는 로직을 삽입했습니다.

*   코스튬 아이템을 그릴 때, 해당 스킨이 연결된 업적을 아직 깨지 못했다면 **"LOCKED"** 와 **"REQ: [업적 이름]"** (빨간색 텍스트)을 표기하고 버튼을 잠급니다(비활성화).
*   코스튬을 구매할 때를 처리하는 `CostumeManager.cs`의 `Purchase` 내부에서도 한 번 더 잠금 상태를 검증(`IsCostumeUnlocked`)하여 만약의 경우에도 비정상적인 구매가 이루어지지 않도록 보안을 강화했습니다.

---

> [!TIP]
> 당장은 기존 코스튬(BUNNY GIRL, BIKINI 등)에 업적을 매핑하지 않았으므로 모두 자유롭게 열려있는 상태입니다. 추후 스크립트 내 초기화(`InitializeAchievements`) 함수에서 `RewardCostumeId = "bunny_girl"` 등으로 조건만 달아주면 자동으로 상점에서 잠기며 업적 해금을 유도하게 됩니다!
