# OfficeLook Sprite Preview Set

This folder contains 35 review-only OfficeLook sprites. They are not wired into
the Unity costume system and are intentionally stored outside
`Assets/Resources/Characters/Costumes`.

## Output

- `Sprites/`: transparent, normalized 600×1180 RGBA PNG files
- `ChromaSources/`: original generated PNG files on green chroma backgrounds

## Variant count

- Emotions: 19
- ItemUse: 9
- Position: 2
- SkillUpgrade: 3
- States: 2

## Locked design prompt

Preserve Yomi's original identity and palette: dark charcoal-purple hair, cool
lavender highlight band, single ahoge, golden eyes when open, original body
proportions and seated composition. Use very long, smooth, pin-straight hair
without curls, waves, or outward-feathered ends. Preserve the approved OfficeLook
outfit across every variant: ivory rolled-sleeve collared blouse, navy ribbon,
name badge, black belt, fitted navy pencil skirt, and black low-heel pumps.

For each variant, the matching Pajama sprite was used only as the authoritative
pose, expression, prop, effect, and composition reference. Only the hairstyle and
costume were replaced. Each image was generated separately with the built-in
image generation tool on a flat chroma background, locally extracted to alpha,
and normalized to 600×1180.
