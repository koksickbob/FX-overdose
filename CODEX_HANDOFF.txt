[최근 요청 및 구현 상태]

1. 튜토리얼 UI 하이라이트

`docs/03_UI/튜토리얼_UI_하이라이트_인수인계.md`와 `docs/트레이딩_기초_용어_만화_시나리오.md`를 참고하여 튜토리얼 연결을 보강했다.

- AUTO/USER 거래 모드 버튼 하이라이트
- AUTO STYLE 탭 하이라이트
- 통합 SKILL 버튼 하이라이트
- 런타임 생성 UI가 준비될 때까지 하이라이트 바인딩 재시도

관련 파일:

- `Assets/Scripts/System/TutorialManager.cs`
- `Assets/Scripts/UI/SettingsMenuController.cs`
- `Assets/Scripts/UI/Chart/TradingPanelUIController.cs`
- `Assets/Scripts/UI/ActiveSkillHUDController.cs`

2. 트레이딩 기초 용어 만화

기존 스토리 컷씬과 `docs/05_Art_Assets/스토리_아트_발주서.md`의 화풍을 참고해 4개의 튜토리얼 컷을 제작했다.

- `Assets/Resources/Tutorial/Terminology/Panel01_LongShort.png`
- `Assets/Resources/Tutorial/Terminology/Panel02_Margin.png`
- `Assets/Resources/Tutorial/Terminology/Panel03_Leverage.png`
- `Assets/Resources/Tutorial/Terminology/Panel04_Liquidation.png`

공통 규격은 `1672x941` PNG다. 각 이미지에는 시나리오의 한국어 설명과 말풍선이 직접 포함되어 있다.

`ComicCutsceneController`는 위 이미지를 `Resources.Load<Sprite>()`로 순서대로 불러온다. 이미지에 대사가 포함되므로 기존 하단 자막 패널은 비활성화했으며, 이미지 표시 영역을 하단까지 확장했다.

관련 파일:

- `Assets/Scripts/UI/ComicCutsceneController.cs`
- `Assets/Scripts/System/TutorialManager.cs`
- `docs/트레이딩_기초_용어_만화_시나리오.md`

[현재 워크트리 주의사항]

현재 변경 사항은 아직 커밋되지 않았다. 기존 사용자 변경과 이번 작업이 섞여 있으므로 임의로 되돌리거나 전체 스테이징하지 않는다.

확인된 변경 파일:

- `Assets/Fonts/PFStardustBold Dynamic SDF.asset`
- `Assets/Scripts/System/TutorialManager.cs`
- `Assets/Scripts/UI/ActiveSkillHUDController.cs`
- `Assets/Scripts/UI/Chart/TradingPanelUIController.cs`
- `Assets/Scripts/UI/ComicCutsceneController.cs`
- `Assets/Scripts/UI/SettingsMenuController.cs`
- `Assets/Resources/Tutorial/` 신규 폴더와 이미지/메타 파일
- 모델 파일의 신규 `.meta` 파일 2개

폰트 에셋 변경량이 크므로 자동 재생성 또는 사용자 변경 여부를 확인하고 다뤄야 한다.

[다음 확인 항목]

1. Unity Editor에서 튜토리얼을 처음부터 실행한다.
2. AUTO/USER, AUTO STYLE, SKILL 하이라이트 위치가 실제 UI와 일치하는지 확인한다.
3. 용어 만화 4컷이 순서대로 표시되고 클릭으로 진행되는지 확인한다.
4. 말풍선과 글자가 화면비 및 모바일 해상도에서 잘리지 않는지 확인한다.
5. 이미지에 대사가 포함된 상태에서 별도 하단 자막이 중복되지 않는지 확인한다.
6. SKIP 버튼과 전체 화면 다음 컷 버튼의 클릭 우선순위를 확인한다.
